## TL;DR

**v6.0.0 was tagged locally on 2026-05-09 with an indefensible bind.** Independent review (Gemini ×4, Codex unavailable) surfaced three classes of issue:

1. **Verdict-invalidating methodology defects** in the P9 harness — the bind we cited doesn't actually evidence what the annotation claims it evidences.
2. **Critical code regressions** in the routing/assembly/ingestion paths — the same v5.0.1 silent-fail pattern we promised to close, recurring at a deeper layer.
3. **Architectural concerns** about recursive corpus, self-grading bias, and async-sync pipeline boundaries.

**v6 polish closes all three** and ships v6.0.0 *once*, with an honest annotation reflecting whatever the corrected methodology produces — positive bind, kill receipt, or inconclusive. The local tag stays unpushed until the polish lands.

This is not v6.0.1+v6.1 split into hot-fix and re-validation. It's *completing v6*. One spec, one milestone, one tag.

## Source — what this completes, not regresses

PROJECT.md's v6 thesis is unchanged: **v6 closes the lazy-memory surface by surfacing the moments that produced decisions and lessons, not just summaries about them.** That's the right next move on the parable substrate. v5 shipped the *storing* leg; v6 ships the *recall* leg. ## What polish closes (the must-fix list)

### Verdict-invalidating methodology defects (P9 harness)

AND created_at_epoch_ms BETWEEN ? AND ?`). **What was measured is not what shipped.** | `arm-transcript.ts:58-76` vs `transcript-routing.ts:98-100` | Replace harness B-arm with a direct call to the production `routeFromArtifact` function. | **V-02** | Three-prong rubric requires "cite specifically with `session_id` + `turn_index`" — but A-arm context is `[ctx-${i+1}] ${summary}` with no metadata while B-arm is fed `[from session_id=..., turn_index=...]` explicitly. **The lift is partly measuring metadata access, not engagement with deliberation.** | `arm-summary.ts:80,98` vs `arm-transcript.ts:160` | Either (a) give A-arm the same metadata access (matching what summaries actually carry in production assembly), or (b) remove prong-2's metadata-citation requirement and rebuild it as "engages with the *content* of the cited material." |

### Code regressions (the v5.0.1 pattern recurring)

| Layer | Severity | Issue | Fix |
|---|---|---|---|
| **Routing** | CRITICAL (1-line) | Null `body` causes `.substring()` to throw, breaking non-throwing contract | `(artifact.query_text ?? rows[0].body ?? '').substring(...)` |
| **Routing** | CRITICAL (1-line) | Telemetry DB exception bypasses bi-encoder fallback when reranker fails | Wrap `incrementRerankerFallbackCounter` in its own try/catch |
| **Routing** | RECOMMENDED | Time-window sort `ORDER BY turn_index ASC LIMIT 20` truncates chunks adjacent to artifact creation time when sessions exceed window | `ORDER BY ABS(created_at_epoch_ms - ?) ASC` with artifact's creation timestamp |
| **Assembly** | CRITICAL | `appendDeliberationSurfaceToPayload` returns a freshly-constructed object; drops `commitEffects?: () => void` and other payload keys, silently breaking experience-pattern hooks | `return { ...payload, content: newContent, ... }` |
| **Assembly** | CRITICAL | Async wrapper returns `Promise<InjectPayload>` even on the early-return-non-opt-in branch; sync callers get `[object Promise]` injection or hard crash | Either make `assembleFullContext` natively async (preferred), or split the function: sync wrapper for opt-out, async-only path when opt-in is true |
| **Assembly** | CRITICAL | Bi-encoder budget asymmetry computed but `bi_encoder_budget_applied` flag is discarded by `formatDeliberationSurfaceSection`; consumer (LLM) cannot tell whether spans are reranker-confirmed or low-confidence fallback | Surface a header-level annotation when `bi_encoder_budget_applied` is true (e.g., `## Deliberation Surfaced (low-confidence retrieval)`) |
| **Assembly** | RECOMMENDED | Token-budget greedy-pack measures span text only; ignores advisory-header (~8-10 tokens) and `\n\n` separators; can overflow strict cap | Pre-deduct header + separator overhead from the cap before the pack loop |
| **Ingestion** | CRITICAL | `upsertChunk` uses `INSERT OR IGNORE` on metadata but the loop unconditionally rewrites the vec0 row with a vector of the *new* body; metadata and embeddings drift out of sync if redaction rules change | Switch metadata to `INSERT ... ON CONFLICT(...) DO UPDATE SET body = ?, ...` to keep both layers in lock-step |
| **Ingestion** | CRITICAL | No session-level cleanup before re-ingestion; if new run yields fewer chunks (`sub_index` 0,1 vs old 0,1,2), trailing rows are orphaned forever | `DELETE FROM transcript_chunk_v6 WHERE session_id = ?` before the chunk loop on re-ingest, OR `DELETE FROM transcript_chunk_v6 WHERE session_id = ? AND sub_index > ?` after the loop with the max written sub_index |
| **Ingestion** | CRITICAL | Empty-body chunks bypass vec DELETE; when redaction empties a previously-populated chunk, old vector survives polluting top-K | Always run vec DELETE for the rowid before the empty-body skip |
| **Ingestion** | CRITICAL | Missing JSONL → `fs.readFileSync` throws → `parseSessionJsonl` catches and returns `turns: []` → `ingestSession` returns success-with-zero-chunks. Total pipeline failure marked complete. **Tests explicitly codify this bug as expected behavior.** | Distinguish "no turns parsed" from "file did not exist." Missing-file path emits explicit telemetry + sets `result.errors = -1` (signal sentinel) so the queue-row update can flag operator-visible failure. Test rewritten to assert visible failure. |
| **Ingestion** | CRITICAL | `body.split(/(?<=[.!?])\s+/)` in `chunkTranscript` consumes whitespace including newlines/tabs; sub-chunks rejoined via `.join(' ')` permanently destroy structural formatting in code blocks, JSON, stack traces | Format-preserving sub-chunker: track split offsets, slice the original `body` at sentence boundaries, preserve in-between whitespace |
| **Ingestion** | CRITICAL | Single-sentence chunks > 5000 tokens bypass the 1500-token sub-chunk threshold (no sentence boundary to split on); embedding API throws on context limit; outer catch silently increments error counter; critical code blocks left unsearchable | Hard-cap sub-chunks at the embedder's token limit; force-split on token boundary when sentence-respecting fails |

## Methodology gates promoted from this polish

The polish itself promotes new standard-practice items for all v6+ engineering phases:

1. **Production-shape integration tests** — every engineering phase ships an integration test that runs the production code path against a sanitized snapshot of the actual production DB, not synthetic fixtures only. Promoted from v5.0.1 lesson but properly applied this time.
2. **Adversarial external review** — every engineering phase close-out includes external-reviewer (Codex / Gemini / human) signed-off SUMMARY. Promoted from this polish.
3. **Tests must assert visible failures** — never assert "no error on missing dependency"; assert "explicit operator-visible failure." Test-discipline lint added to CI.
4. **Methodology critique pre-commit** — every empirical phase's CONTEXT.md includes a "what would invalidate this measurement" section, pre-committed. Forces methodology adversarialism into the discipline.
