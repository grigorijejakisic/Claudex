# Plan 07.5-01 — Handoff schema module

## Goal

Land a self-contained TypeScript module at `src/angel/handoff-writer.ts` that:

1. Defines the locked Phase 7.5 schema as TS types (`HandoffHeader`, `HandoffInput`, `HandoffStatus`).
2. Provides `writeHandoff(targetPath, input)` that emits a valid hybrid file with atomic write semantics.
3. Provides `parseHandoffHeader(raw)` returning the parsed YAML header or null.
4. Provides `validateHandoffHeader(header)` returning a list of validation errors (empty on valid).
5. Is consumed in Wave 2 by `memory-md-writer.ts:renderHandoff` (Plan 07.5-02) and the migration script (Plan 07.5-02).

This plan ships the module and its tests only. No call-sites updated yet.

## Schema spec (locked in CONTEXT.md, restated)

YAML header (required: `status`, `phase`; optional: `summary`, `topic`, `created_at_epoch_ms`):

```yaml
---
status: active | archived | paused
phase: <N>                    # integer or decimal as string ("4.1" or 5)
summary: <one-line summary>   # OPTIONAL but RECOMMENDED — Phase 5 SC#4 prime reads this
topic: <slug>                 # OPTIONAL — used by MEMORY.md `## Handoff` one-line
created_at_epoch_ms: <ms>     # OPTIONAL — auto-set by writer if not provided
---
```

Body (locked order):

```markdown
# <YYYY-MM-DD> — <topic-or-summary>

**What we found:** ...

**What we decided:** ...

**What's next:** ...

**Where to look:** ...
```

## Tasks

<task id="07.5-01-01">
  <subject>Create `src/angel/handoff-writer.ts` with types, parser, validator, writer</subject>
  <description>
Implement the module from scratch. No imports from other repo modules except `node:fs` and `node:path`.

**Types (top of file):**
```typescript
export type HandoffStatus = 'active' | 'archived' | 'paused';

export interface HandoffHeader {
  status: HandoffStatus;
  phase: string;                  // string to handle "4.1" decimals losslessly
  summary?: string;
  topic?: string;
  created_at_epoch_ms?: number;
}

export interface HandoffInput {
  status: HandoffStatus;
  phase: string | number;
  summary?: string;
  topic?: string;
  created_at_epoch_ms?: number;
  // Body sections
  whatWeFound: string;
  whatWeDecided: string;
  whatsNext: string;
  whereToLook: string;
}

export interface HandoffValidationError {
  field: string;
  reason: string;
}
```

**`validateHandoffHeader(header: Partial<HandoffHeader>): HandoffValidationError[]`:**
- Returns `[]` if `status` is one of `active|archived|paused` AND `phase` is a non-empty string.
- Otherwise returns one entry per invalid/missing field.

**`parseHandoffHeader(raw: string): HandoffHeader | null`:**
- Match `^---\n([\s\S]*?)\n---\n` at the start of `raw`. Return null if no match.
- For each `key: value` line in the captured group, extract by regex `^([a-z_]+):\s*"?([^"\n]*)"?\s*$`.
- Convert `created_at_epoch_ms` to number if present; otherwise leave undefined.
- Validate via `validateHandoffHeader`. If invalid, return null.
- Return the typed header.

**`renderHandoffMarkdown(input: HandoffInput): string`:**
- Build YAML block from non-undefined fields. Always emit `status` + `phase` (in that order). Then emit `summary`, `topic`, `created_at_epoch_ms` if present (in that order).
- Body title: `# ${YYYY-MM-DD} — ${topic ?? summary ?? 'untitled'}` where date is `new Date(input.created_at_epoch_ms ?? Date.now()).toISOString().slice(0, 10)`.
- Four sections in locked order: `**What we found:** ${whatWeFound}\n\n**What we decided:** ${whatWeDecided}\n\n**What's next:** ${whatsNext}\n\n**Where to look:** ${whereToLook}\n`.

**`writeHandoff(targetPath: string, input: HandoffInput): void`:**
- Build a Partial<HandoffHeader> from input.
- Run `validateHandoffHeader`. If errors: throw `new Error('handoff validation failed: ' + JSON.stringify(errors))`.
- If `created_at_epoch_ms` undefined: stamp `Date.now()` BUT preserve input's epoch in the rendered Markdown so round-trip is stable.
- Render the full file via `renderHandoffMarkdown`.
- Atomic write: write to `targetPath + '.tmp'`, then `fs.renameSync(tmp, target)`. If target's parent directory doesn't exist, create with `fs.mkdirSync(path.dirname(target), { recursive: true })` BEFORE the tmp write.

**Coercion notes:**
- `input.phase` accepts `string | number`; serialize as string. If numeric, emit `phase: 5` (no quotes); if string with non-digit chars (decimal, e.g. "4.1"), emit quoted: `phase: "4.1"`. This matches the `src/tests/integration/handoff-pickup-one-turn.test.ts:84` shape.
- `input.summary` if it contains a colon or quote: write minimally-escaped (wrap in double quotes; escape inner quotes via `\"`). Otherwise unquoted. The Phase 5 parser at `session-start.ts` uses `^summary:\s*(.+)$` which handles both.

<task id="07.5-01-02">
  <subject>Write unit tests covering schema, validation, atomic write, round-trip</subject>
  <description>
Create `src/tests/angel/handoff-writer.test.ts` with the following test groups:

**Group 1 — `validateHandoffHeader`:**
- `valid: status=active + phase="5"` → `[]`
- `invalid status=foo` → 1 error on `status`
- `missing phase` → 1 error on `phase`
- `empty phase` → 1 error on `phase`
- `valid status=archived + phase="4.1"` → `[]`

**Group 2 — `parseHandoffHeader`:**
- valid header with status + phase only → returns object with both, summary/topic/created_at_epoch_ms undefined
- valid header with all 5 fields → returns full object; `created_at_epoch_ms` is `number`
- malformed (no closing `---`) → returns `null`
- invalid status value (`status: bogus`) → returns `null`
- quoted phase (`phase: "4.1"`) → returns object with `phase === "4.1"`
- summary containing colon (`summary: "Resume: phase 5"`) → returns with `summary === "Resume: phase 5"`

**Group 3 — `renderHandoffMarkdown`:**
- minimal input (status, phase, 4 body sections) → output starts `---\nstatus: active\nphase: 5\n---\n# `
- input with `topic` set → title line uses `topic`
- input with only `summary` and no `topic` → title line uses `summary`
- input with neither → title line uses `untitled`
- locked section order: `**What we found:**` precedes `**What we decided:**` precedes `**What's next:**` precedes `**Where to look:**` in the rendered string

**Group 4 — `writeHandoff` (filesystem):**
- writes valid file to a tmp path; `fs.readFileSync` of result matches `renderHandoffMarkdown` output
- creates parent dir if missing
- invalid input (missing `phase`) → throws `Error` matching `/handoff validation failed/`
- atomic rollback: monkey-patch `fs.renameSync` to throw → confirm `target` does NOT exist after the throw, and `target + '.tmp'` may or may not exist (cleanup not strictly required, but pre-existing target must remain untouched). Test pre-condition: pre-existing valid file at target → after throw, that file is byte-identical to before.

**Group 5 — round-trip:**
- For 5 hand-written `HandoffInput` fixtures: `parseHandoffHeader(renderHandoffMarkdown(input))` returns a header object whose `status`, `phase`, `summary`, `topic`, `created_at_epoch_ms` deep-equal the input's (modulo `created_at_epoch_ms` defaulting if input omitted it).

Use `os.tmpdir()` + `fs.mkdtempSync` for filesystem tests; `afterEach` cleanup with `fs.rmSync(tmpDir, { recursive: true, force: true })`. Mirror the pattern from `src/tests/angel/memory-md-writer.test.ts`.
