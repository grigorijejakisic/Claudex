# Plan 16-03: Windows onboarding fixture — autonomous fill-in for post-install state

## Objective

Create `docs/onboarding/windows.md` covering the Windows 11 install regression check (VER-03 / PLAT-08). Per `16-CONTEXT.md` plan_authorization, this fixture is the only one of the three platforms where the orchestrator can legitimately fill in some fields autonomously: Claudex v4.1 IS installed on this Windows machine right now, every Phase 14/15 command has been verified live here, and `bun run doctor` is currently returning exit 0 with the documented `15-SUMMARY.md` shape.

The fixture explicitly delineates the autonomous half (post-install verification, recorded from current state) from the HITL half (fresh-VM install of Bun / Ollama / Python from clean Windows 11). The latter remains operator-runnable because PLAT-08's intent is regression check on a *fresh* VM, not "verify it still works on the dev machine where it's been running for weeks."

## Why this comes after 16-01 and is parallelizable with 16-02

This plan and 16-02 both write fixture files under `docs/onboarding/`. They touch different files (`windows.md` vs `macos.md` + `linux.md`), so they can land in any order in Wave 2 — sequenced or parallel. Both depend on Plan 16-01's anchor in §Troubleshooting for cross-links to resolve.

### 5. Run install

**Command (autonomous):**
```cmd
install.bat
```
The wrapper pre-flights Bun, then runs `call bun install --frozen-lockfile && call bun run build && call bun run setup`. The `call` prefix is required on Windows because `bun` ships as `bun.cmd`; without `call`, control transfers to `bun.cmd` and never returns to `install.bat` — known Phase 14 gotcha, fixed before close.

`bun run setup` is the substantive bootstrap: Bun version → Ollama detect → model pull (`snowflake-arctic-embed2`) → reranker venv at `services/.venv` → projects-dir scaffold → DB at `~/.claudex/db/claudex.db` (Windows: `%USERPROFILE%\.claudex\db\claudex.db`) → hooks at `~/.claude/settings.json` (Windows: `%USERPROFILE%\.claude\settings.json`). Idempotent on re-run.

**Expected (autonomous):** install.bat exits 0. `bun run setup` prints 8 numbered steps. Re-running install.bat is idempotent (Phase 14 verified live: "Live smoke `cmd /C install.bat` runs end-to-end exit 0 twice in a row" per `14-SUMMARY.md`).
