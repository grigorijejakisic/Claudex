# Plan 09-02 — Delete cara-reasoning.ts (sub-phase 9.1)

## Goal

Delete `src/angel/cara-reasoning.ts` (CARA opinion-formation network) and
its sole heartbeat callsite (Phase 4e3c). With sub-phase 9.2 (Plan 09-01)
already shipped, `autonomous-investigator.ts` no longer imports from
cara-reasoning, so this deletion is now safe per
CONTEXT.md `<decisions>.### Module dependencies`.

Also delete the dedicated test file `src/tests/angel/cara-reasoning.test.ts`
(per CONTEXT.md `<decisions>.### Test deletion` — module-specific tests go
with the module).

## Why this is sub-phase 9.1 but ships in Wave 2

CONTEXT.md numbers cara-reasoning as 9.1 (semantic ordering). It ships in
Wave 2 because Plan 09-01 (autonomous-investigator) had to clear first to
break the import edge from `autonomous-investigator.ts:21` into cara-reasoning's
`reinforceOpinion` / `weakenOpinion` / `contradictOpinion` / `Opinion` exports.
After Plan 09-01 lands, those four exports become unused — this plan deletes
them with the rest of the file.
