<execution_context>
**Helper contract:**
```ts
// src/shared/projects-dir.ts
import * as os from 'os';
import * as path from 'path';
import * as fs from 'fs';

/**
 * Resolves the projects directory used by Claudex's scope detection,
 * content routing, MCP server instructions, and assembly sections.
 *
 * - If CLAUDEX_PROJECTS_DIR is set, returns it (resolved against cwd if relative).
 * - Otherwise returns path.join(os.homedir(), 'Projects').
 *
 * Ensures the directory exists (best-effort mkdir -p). Never throws — if the
 * directory cannot be created, the resolved path is still returned and the
 * caller can decide what to do.
 */
export function getProjectsDir(): string;
```

**Why a single helper:** the env var is read in many places today (or rather, the path is hardcoded in many places today). Centralizing in one helper means the env var override flows everywhere and any future change to the default lives in one file. This matches the project's existing pattern (`src/shared/paths.ts` for db/config paths).

**What "ensure exists" means:** call `fs.mkdirSync(resolved, { recursive: true })` inside a try/catch. On EEXIST or success, return the path. On any other error, log to stderr and still return the path — getProjectsDir() must never throw because it's called from hot paths in scope-detector and content-router that already use try/catch + fallback.

**Audit method:** run `grep -rn "Desktop/Projects" src/` (already done, 10 files identified). For each hit, classify:
- **code-fix** — actual filesystem-path construction that needs replacement (e.g., `path.join(os.homedir(), 'Desktop', 'Projects')` in `scope-detector.ts:133` and `content-router.ts:100`)
- **string-text-fix** — user-facing text or MCP instructions text containing the literal path (e.g., `recall-server.ts:127`, `sections.ts:71`)
- **comment-update** — JSDoc/comment mentioning the path; update to mention `CLAUDEX_PROJECTS_DIR` instead
- **test-fixture-keep** — test code asserting on the literal old default; either rewrite to use os.homedir-derived path, or keep with reason if the test is platform-specific

Also run `grep -rn "path.join(os.homedir(), 'Desktop'" src/` and `grep -rn '"Desktop", "Projects"' src/` to catch the joined forms.

**Out of scope:**
- Replacing any callsite — 14-02 does that
- Touching `services/reranker.py` (Python; separate)
- Modifying `~/.claudex/projects.json` registry data
</execution_context>

**Action:**
Write `C:\Users\Grigorije\Desktop\Projects\CLAUDEXv3\src\shared\projects-dir.ts` matching the contract above. Implementation:

```ts
import * as os from 'os';
import * as path from 'path';
import * as fs from 'fs';

const ENV_VAR = 'CLAUDEX_PROJECTS_DIR';

export function getProjectsDir(): string {
  const fromEnv = process.env[ENV_VAR];
  const resolved = fromEnv && fromEnv.length > 0
    ? path.resolve(fromEnv)
    : path.join(os.homedir(), 'Projects');

  try {
    fs.mkdirSync(resolved, { recursive: true });
  } catch (err) {
    // Best-effort: log and continue. Callers must not depend on existence.
    process.stderr.write(`[projects-dir] mkdir failed for ${resolved}: ${(err as Error).message}\n`);
  }

  return resolved;
}
```

Add a small `getProjectsDirEnvVarName()` exported constant or function if it improves testability, otherwise keep the module minimal.
