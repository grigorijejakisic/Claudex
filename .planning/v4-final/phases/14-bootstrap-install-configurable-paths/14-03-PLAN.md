<execution_context>
**Why a `bootstrap-steps/` subdirectory:** keeping each step in its own module means we can unit-test each step in isolation with dependency injection, and `setup.ts` becomes a thin orchestrator. The existing setup.ts is a single ~270-line file; extending it inline would push past 500 lines and tangle pre-checks with the dirs/DB/hooks core. Decomposition matches the project's existing pattern (e.g., `src/angel/` is a directory of small modules).

**Step contracts (every step):**
```ts
export interface StepResult {
  ok: boolean;          // true if step succeeded; false = setup must exit 1 (unless this is reranker, where false = warn+continue)
  message: string;      // human-readable summary, printed by setup.ts orchestrator
  warning?: string;     // optional non-fatal advisory (used by reranker step on best-effort failure)
}

export async function step(opts?: StepOptions): Promise<StepResult>;
```

Each step returns; the orchestrator decides exit code.

**Idempotency rules:**
- Bun version check: pure read, idempotent
- Ollama detect: pure read, idempotent
- Model pull: `ollama pull` is idempotent itself (Ollama skips if layers exist)
- Reranker bootstrap: idempotent via three short-circuits — (a) if `/health` returns 200, skip spawn; (b) if `services/.venv/` exists with required packages installed, skip pip install; (c) if a stale PID file points to a dead process, clean up and respawn
- Projects-dir ensure: `getProjectsDir()` already does idempotent mkdir

**Cross-platform notes:**
- Bun version: `bun --version` works on all OSes; parse with simple semver compare
- Ollama on Windows: detect via `where.exe ollama` OR `spawn('ollama', ['--version'])` with `ENOENT` handling. Prefer the latter (uniform with POSIX)
- Python detection: try `python3 --version` first (Mac/Linux convention), fall back to `python --version` (Windows convention). If neither found, print install link
- Reranker spawn: use `child_process.spawn` with `detached: true` + `unref()` on Windows; same on POSIX (the existing RerankerSupervisor pattern is already cross-platform — read it for reference)
- Health check: `fetch('http://localhost:7439/health')` with 60s exponential-backoff polling

**Delegation to RerankerSupervisor:**
Two viable approaches:
- **A (recommended):** setup imports a small shared helper from `src/angel/reranker-supervisor.ts` (or a new `src/shared/reranker-bootstrap.ts`) that handles spawn + venv + health-wait without the full Angel-managed lifecycle. This avoids running an Angel process from setup. The helper produces an externally-managed reranker that Angel later detects on its first heartbeat.
- **B:** setup spawns Angel directly (`node dist/angel/index.cjs &` detached), and Angel's RerankerSupervisor handles the reranker. Cleaner but means setup leaves an Angel process running, which may surprise the user.

Pick A. The new `src/shared/reranker-bootstrap.ts` (if introduced) shares its spawn + health-poll utilities with `RerankerSupervisor` so we don't duplicate logic.

import { execFileSync } from 'child_process';

const MIN_BUN = '1.3.0';

export interface BunVersionStepOptions {
  execFn?: typeof execFileSync;
  minVersion?: string;
}

export interface StepResult { ok: boolean; message: string; warning?: string; }

export async function checkBunVersion(opts: BunVersionStepOptions = {}): Promise<StepResult> {
  const exec = opts.execFn ?? execFileSync;
  const min = opts.minVersion ?? MIN_BUN;
  try {
    const out = exec('bun', ['--version'], { encoding: 'utf-8' }).trim();
    if (semverGte(out, min)) {
      return { ok: true, message: `Bun ${out} (>= ${min}) detected` };
    }
    return { ok: false, message: `Bun ${out} too old. Need >= ${min}. Upgrade: https://bun.sh` };
  } catch {
    return { ok: false, message: `Bun not found. Install: https://bun.sh` };
  }
}

function semverGte(a: string, b: string): boolean { /* simple parser, no dependency */ }

import { execFileSync } from 'child_process';

const OLLAMA_API = 'http://localhost:11434/api/tags';

export interface OllamaDetectOptions {
  execFn?: typeof execFileSync;
  fetchFn?: typeof fetch;
  platform?: NodeJS.Platform;
}

export async function detectOllama(opts: OllamaDetectOptions = {}): Promise<StepResult> {
  const exec = opts.execFn ?? execFileSync;
  const f = opts.fetchFn ?? fetch;
  const platform = opts.platform ?? process.platform;

  // 1. Is the binary on PATH?
  try {
    exec('ollama', ['--version'], { encoding: 'utf-8', timeout: 5000 });
  } catch {
    return { ok: false, message: ollamaInstallMessage(platform) };
  }

  // 2. Is the daemon running?
  try {
    const r = await f(OLLAMA_API, { signal: AbortSignal.timeout(3000) });
    if (!r.ok) return { ok: false, message: `Ollama installed but daemon returned ${r.status}. Start: 'ollama serve'` };
  } catch {
    return { ok: false, message: `Ollama installed but not running. Start: 'ollama serve' (or restart if launched via app)` };
  }

  return { ok: true, message: 'Ollama present and running' };
}

function ollamaInstallMessage(platform: NodeJS.Platform): string {
  if (platform === 'darwin') return `Install Ollama: https://ollama.com/download/mac (or 'brew install ollama')`;
  if (platform === 'linux') return `Install Ollama: curl -fsSL https://ollama.com/install.sh | sh`;
  if (platform === 'win32') return `Install Ollama: https://ollama.com/download/windows`;
  return `Install Ollama: https://ollama.com/download`;
}
```

import { execFileSync, spawn } from 'child_process';

const MODEL = 'snowflake-arctic-embed2';

export async function pullEmbeddingModel(opts: {
  execFn?: typeof execFileSync;
  spawnFn?: typeof spawn;
  modelName?: string;
} = {}): Promise<StepResult> {
  const exec = opts.execFn ?? execFileSync;
  const sp = opts.spawnFn ?? spawn;
  const model = opts.modelName ?? MODEL;

  // 1. Already pulled?
  try {
    const list = exec('ollama', ['list'], { encoding: 'utf-8' });
    if (list.includes(model)) return { ok: true, message: `Model ${model} already present` };
  } catch (err) {
    return { ok: false, message: `ollama list failed: ${(err as Error).message}` };
  }

  // 2. Pull (5 min timeout, stream progress)
  return new Promise((resolve) => {
    const child = sp('ollama', ['pull', model], { stdio: 'inherit' });
    const timer = setTimeout(() => { child.kill(); resolve({ ok: false, message: `ollama pull ${model} timed out after 5 min` }); }, 5 * 60_000);
    child.on('exit', (code) => {
      clearTimeout(timer);
      if (code === 0) resolve({ ok: true, message: `Pulled ${model}` });
      else resolve({ ok: false, message: `ollama pull ${model} failed (exit ${code})` });
    });
  });
}
```

```ts
import { spawn, execFileSync } from 'child_process';
import * as fs from 'fs';
import * as path from 'path';

const HEALTH_URL = 'http://localhost:7439/health';

export interface RerankerBootstrapOptions {
  projectRoot: string;          // resolves services/.venv and services/reranker.py
  fetchFn?: typeof fetch;
  spawnFn?: typeof spawn;
  execFn?: typeof execFileSync;
  healthTimeoutMs?: number;     // default 60_000
  pythonCandidates?: string[];  // default ['python3', 'python']
}

export async function bootstrapReranker(opts: RerankerBootstrapOptions): Promise<StepResult> {
  const f = opts.fetchFn ?? fetch;

  // 1. Already serving? Skip everything.
  if (await healthOk(f, 1500)) {
    return { ok: true, message: 'Reranker already healthy on :7439 (skipping bootstrap)' };
  }

  // 2. Find Python
  const python = findPython(opts.execFn ?? execFileSync, opts.pythonCandidates ?? ['python3', 'python']);
  if (!python) {
    return {
      ok: true, // best-effort: don't hard-fail
      message: 'Reranker bootstrap skipped',
      warning: 'Python 3.11+ not found. Install: https://www.python.org/downloads/. Reranker will not run; bi-encoder fallback is degraded mode.',
    };
  }

  // 3. Ensure venv
  const venvDir = path.join(opts.projectRoot, 'services', '.venv');
  if (!fs.existsSync(venvDir)) {
    const venvResult = ensureVenv(python, venvDir, opts.execFn ?? execFileSync);
    if (!venvResult.ok) return { ok: true, message: 'Reranker bootstrap skipped', warning: venvResult.message };
  }

  // 4. pip install requirements (idempotent — pip skips already-satisfied)
  const pipResult = pipInstall(venvDir, path.join(opts.projectRoot, 'services', 'requirements.txt'), opts.execFn ?? execFileSync);
  if (!pipResult.ok) return { ok: true, message: 'Reranker bootstrap skipped', warning: pipResult.message };

  // 5. Spawn reranker as detached background process
  spawnReranker(venvDir, opts.projectRoot, opts.spawnFn ?? spawn);

  // 6. Wait for /health 200 (60s budget, exponential backoff)
  const healthy = await waitForHealth(f, opts.healthTimeoutMs ?? 60_000);
  if (!healthy) {
    return {
      ok: true,
      message: 'Reranker bootstrap skipped',
      warning: 'Reranker spawned but /health did not return 200 within 60s. Check context/logs/reranker.log; bi-encoder fallback is degraded mode.',
    };
  }

  return { ok: true, message: 'Reranker healthy on :7439' };
}

// helpers: healthOk, findPython, ensureVenv, pipInstall, spawnReranker, waitForHealth
```

Implementation notes for the executor:
- `healthOk(f, timeoutMs)` — single GET with AbortSignal, returns boolean
- `findPython` — try each candidate via `--version`; return the first that works and is >= 3.11
- `ensureVenv` — `python -m venv services/.venv`
- `pipInstall` — `services/.venv/bin/pip install -r services/requirements.txt` on POSIX, `services/.venv/Scripts/pip.exe install -r services/requirements.txt` on Windows
- `spawnReranker` — detached spawn with `unref()`; redirect stdout+stderr to `context/logs/reranker.log` (mkdir -p first); use the venv's Python; pass the reranker.py path
- `waitForHealth` — exponential backoff starting at 500ms, capped at 5s, total budget 60s

**Cross-platform:**
- venv binary path: `path.join(venvDir, process.platform === 'win32' ? 'Scripts' : 'bin', 'python')` (and same for pip with `.exe` on Windows)
- detached spawn: `{ detached: true, stdio: ['ignore', logFd, logFd] }` then `child.unref()`

**Best-effort fallback:**
If any step fails (Python missing, pip install fails, port conflict, /health timeout), return `{ ok: true, message: 'skipped', warning: '...' }` so the orchestrator continues. This matches CONTEXT.md's decision: don't hard-fail setup on reranker brittleness.
