<objective>
Bridge types, adapter callbacks, and plugin entry point: the adapter layer that wires all core subsystems into OpenClaw via a persistent in-process globalThis Symbol bridge.

Purpose: The OpenClaw bridge adapter maps Pi SDK extension events (onInit, context, tool_result, message_end, session_before_compact) to core pipeline calls via a globalThis-registered bridge object. Unlike CC hooks' ephemeral process lifecycle, the bridge opens DB once in activate() and keeps it open for the entire session. The plugin-entry.ts provides the standard OpenClaw activate() function that installs the bridge and registers session_end cleanup. Without this, Claudex v3 has no OpenClaw runtime.

Output: `bridge-types.ts` (BRIDGE_KEY, interfaces, Pi SDK stubs), `bridge-adapter.ts` (5 callback implementations), `plugin-entry.ts` (activate function), and their tests.
</objective>

```typescript
/** globalThis key for bridge discovery. */
export const BRIDGE_KEY = Symbol.for('claudex.v3.bridge');

/**
 * Minimal Pi SDK context stubs — compile-time only, not runtime dependency.
 * Match Architecture Section 3.3 usage patterns.
 */

/** Context object passed to bridge onInit. */
export interface BridgeInitContext {
  sessionKey: string;
  cwd: string;
}

/** Base Pi SDK context (shared by context/tool_result/message_end). */
export interface PiContext {
  sessionKey: string;
  cwd: string;
  messages: Array<{ role: string; content: string }>;
  getContextUsage(): { inputTokens: number; outputTokens: number; contextWindowTokens: number };
  isPostCompaction?: boolean;
}

/** Pi SDK tool_result context. */
export interface PiToolResultContext extends PiContext {
  toolName: string;
  toolInput: Record<string, unknown>;
  toolOutput: Record<string, unknown>;
}

/** Pi SDK message_end context. */
export interface PiMessageEndContext extends PiContext {
  lastAssistantText: string;
  lastUserText: string;
}

/** Pi SDK compaction prep object. */
export interface PiCompactPrep {
  messagesToSummarize: Array<{ role: string; content: string }>;
  turnPrefixMessages: Array<{ role: string; content: string }>;
}

/** Pi SDK compact context. */
export interface PiCompactContext extends PiContext {}

/** Pi SDK runtime (passed to session_before_compact). */
export interface PiRuntime {}

/** Standard Pi SDK extension interface. */
export interface PiExtension {
  name: string;
  context?(ctx: PiContext): Promise<void>;
  tool_result?(ctx: PiToolResultContext): Promise<void>;
  message_end?(ctx: PiMessageEndContext): Promise<void>;
  session_before_compact?(ctx: PiCompactContext, prep: PiCompactPrep, runtime: PiRuntime): Promise<void>;
}

/** OpenClaw plugin API for registration. */
export interface OpenClawPluginApi {
  registerHook(event: string, handler: () => Promise<void> | void): void;
}

/** Bridge object registered on globalThis[BRIDGE_KEY]. */
export interface ClaudexBridge {
  onInit(ctx: BridgeInitContext): Promise<{ content: string; tokenEstimate: number; sources: string[] } | void>;
  onContext(ctx: PiContext): Promise<{ content: string; tokenEstimate: number; sources: string[] } | void>;
  onToolResult(ctx: PiToolResultContext): Promise<void>;
  onTurnEnd(ctx: PiMessageEndContext): Promise<void>;
  onCompact(ctx: PiCompactContext, prep: PiCompactPrep, runtime: PiRuntime): Promise<void>;
}
```

Functions:

`mapTokenUsage(sdkUsage: { inputTokens: number; outputTokens: number; contextWindowTokens: number }): TokenUsage`:
- Maps Pi SDK's `getContextUsage()` return value to the shared `TokenUsage` type
- Computes `utilization = (inputTokens + outputTokens) / contextWindowTokens` clamped to [0, 1]
- Returns a `TokenUsage` object

`createBridgeCallbacks(bctx: BridgeContext): ClaudexBridge`:
- Takes the persistent bridge context (DB, config, project, scope, sessionId, cwd)
- Returns a `ClaudexBridge` object with 5 callback methods
- Each callback is wrapped in try/catch — errors logged via `emitTelemetry(bctx.db, bctx.sessionId, 'bridge_error', { callback, error: String(e) })`, never propagated

**onInit callback** (BridgeInitContext -> session_init):
1. Update bctx.sessionId and bctx.cwd from init context: `bctx.sessionId = ctx.sessionKey; bctx.cwd = ctx.cwd`
2. Re-detect project scope: `bctx.scope = detectProjectScope(ctx.cwd); bctx.project = getProjectId(ctx.cwd)`
3. `createSession(bctx.db, { session_id: ctx.sessionKey, project: bctx.project, scope: bctx.scope ?? undefined, cwd: ctx.cwd, source: 'openclaw-bridge' })`
4. `recoverFromDb(bctx.db)` — re-mirror committed checkpoint rows
5. If observability enabled: `pruneTelemetry(bctx.db, { retentionDays: bctx.config.observability.retention_days, retainErrorCount: bctx.config.observability.retain_error_count })`
6. Full assembly: `const payload = assembleFullContext({ db: bctx.db, project: bctx.project, projectDir: ctx.cwd, config: bctx.config, identityDir: getIdentityDir() })`
7. Emit telemetry: `emitTelemetry(bctx.db, ctx.sessionKey, 'hook_invocation', { hook: 'onInit', duration_ms: elapsed, result: payload.content ? 'inject' : 'skip' }, elapsed)`
8. Return `payload.content ? payload : undefined`

**onContext callback** (PiContext -> before_prompt):
1. Extract prompt from `ctx.messages` — get last user message: `const lastUserMsg = [...ctx.messages].reverse().find(m => m.role === 'user'); const prompt = lastUserMsg?.content ?? ''`
2. Check post-compaction: `const tracking = getCheckpointTracking(bctx.db, bctx.sessionId); const isPostCompaction = ctx.isPostCompaction ?? (tracking?.post_compact_pending === 1)`
3. Map native token usage: `const sdkUsage = ctx.getContextUsage(); const nativeUsage = mapTokenUsage(sdkUsage)`
4. Get token gauge: `const gauge = getTokenGauge({ capabilities: OPENCLAW_CAPABILITIES, nativeUsage })`
5. Detect topic shift (only if not post-compaction and prompt is non-empty):
   - Same pattern as CC's user-prompt-submit: try to create EmbeddingProvider, check availability, create TopicShiftDetector, detect
   - On error: topicShift = null
6. Assemble: `const payload = assembleRegularPrompt({ isPostCompaction, prompt, gauge, topicShift, db: bctx.db, project: bctx.project, projectDir: bctx.cwd, config: bctx.config, identityDir: getIdentityDir() })`
7. If isPostCompaction: `clearPostCompactPending(bctx.db, bctx.sessionId)`
8. Emit telemetry with hook 'onContext'
9. Return `payload.content ? payload : undefined`

**onToolResult callback** (PiToolResultContext -> after_tool):
1. Extract tool fields: `const { toolName, toolInput, toolOutput } = ctx`
2. Run extraction: `processToolObservation({ db: bctx.db, sessionId: bctx.sessionId, project: bctx.project, toolName, toolInput, toolOutput, projectRoot: bctx.cwd })`
3. Update pressure from file paths in toolInput (same pattern as CC's post-tool-use: check file_path, filePath, path keys)
4. Thread tracking: `const tracker = new ThreadTracker(bctx.db, bctx.sessionId); tracker.onAfterTool(undefined, toolName, toolInput); tracker.persist()`
5. Checkpoint threshold check:
   - `const sdkUsage = ctx.getContextUsage(); const nativeUsage = mapTokenUsage(sdkUsage)`
   - `const gauge = getTokenGauge({ capabilities: OPENCLAW_CAPABILITIES, nativeUsage })`
   - `const tracking = getCheckpointTracking(bctx.db, bctx.sessionId)`
   - If `shouldTriggerCheckpoint({ trigger: 'threshold', tokenUsage: gauge ?? undefined, tracking, debounceSeconds: bctx.config.checkpoint.debounce_seconds })`:
     - `const gsd = readGsdState(bctx.cwd)`
     - `await writeCheckpoint({ db: bctx.db, sessionId: bctx.sessionId, project: bctx.project, projectDir: bctx.cwd, trigger: 'threshold', tokenUsage: gauge ?? undefined, gsd: gsd ?? undefined, scope: bctx.scope ?? undefined })`
6. Emit telemetry with hook 'onToolResult'

**onTurnEnd callback** (PiMessageEndContext -> after_turn):
1. Extract texts: `const { lastAssistantText, lastUserText } = ctx`
2. Decision capture with optional embedding classifier (same pattern as CC's stop.ts):
   - Try create EmbeddingProvider if embeddings enabled, check availability, init templates
   - `await captureDecisions({ db: bctx.db, sessionId: bctx.sessionId, project: bctx.project, userText: lastUserText, assistantText: lastAssistantText, mode: 'after_turn', classifier, confidenceThreshold: bctx.config.embeddings.decision_confidence_threshold })`
3. Thread tracking: `const tracker = new ThreadTracker(bctx.db, bctx.sessionId); tracker.onAfterTurn(lastUserText, lastAssistantText)`
4. Checkpoint threshold check (same pattern as onToolResult using ctx.getContextUsage())
5. Emit telemetry with hook 'onTurnEnd'

**onCompact callback** (PiCompactContext, PiCompactPrep, PiRuntime -> before_compact):
1. Get native token gauge via ctx.getContextUsage()
2. `const gsd = readGsdState(bctx.cwd)`
3. Detect enrichment provider: `const enrichProvider = await detectEnrichmentProvider({ baseUrl: bctx.config.enrichment.ollama_base_url, model: bctx.config.enrichment.ollama_model, provider: bctx.config.enrichment.provider }, OPENCLAW_CAPABILITIES)` — on OpenClaw this may return 'openclaw-native' type
4. Write checkpoint: `await writeCheckpoint({ db: bctx.db, sessionId: bctx.sessionId, project: bctx.project, projectDir: bctx.cwd, trigger: 'compaction', tokenUsage: gauge ?? undefined, gsd: gsd ?? undefined, enrichmentProvider: enrichProvider ?? undefined, scope: bctx.scope ?? undefined })`
5. Promote learnings: `promoteLearnings({ db: bctx.db, project: bctx.project, sessionLearnings: [] })`
6. Mark post-compact-pending: `markPostCompactPending(bctx.db, bctx.sessionId)`
7. Emit telemetry with hook 'onCompact'

```typescript
/**
 * OpenClaw plugin entry point.
 * Opens DB once, creates bridge callbacks, registers on globalThis, sets up session_end cleanup.
 * @see Architecture Section 3.3
 */
export function activate(api: OpenClawPluginApi): void {
  try {
    const db = openDatabase(getDbPath());
    const config = loadConfig();
    const cwd = process.cwd();
    const scope = detectProjectScope(cwd);
    const project = getProjectId(cwd);

    const bctx: BridgeContext = {
      db,
      config,
      project,
      scope,
      sessionId: '', // Set by onInit when session starts
      cwd,
    };

    const bridge = createBridgeCallbacks(bctx);

    // Register bridge on globalThis for OpenClaw's extensions.ts to discover
    (globalThis as any)[BRIDGE_KEY] = bridge;

    // Register session_end cleanup
    api.registerHook('session_end', async () => {
      try {
        const startMs = Date.now();

        // Write final checkpoint
        const gsd = readGsdState(bctx.cwd);
        await writeCheckpoint({
          db: bctx.db,
          sessionId: bctx.sessionId,
          project: bctx.project,
          projectDir: bctx.cwd,
          trigger: 'session_end',
          gsd: gsd ?? undefined,
          scope: bctx.scope ?? undefined,
        });

        // Decay and retention
        pruneObservations(bctx.db, bctx.project, {
          pruneThreshold: bctx.config.observations.prune_threshold,
          pruneCount: bctx.config.observations.prune_count,
        });
        applyRetentionPolicy(bctx.db, bctx.project, bctx.config.observations.retention_days);
        decayPressureStratified(bctx.db);

        // End session
        endSession(bctx.db, bctx.sessionId, 'completed');

        // Prune telemetry
        pruneTelemetry(bctx.db, {
          retentionDays: bctx.config.observability.retention_days,
          retainErrorCount: bctx.config.observability.retain_error_count,
        });

        const elapsed = Date.now() - startMs;
        emitTelemetry(bctx.db, bctx.sessionId, 'hook_invocation', {
          hook: 'session_end',
          duration_ms: elapsed,
          result: 'skip' as const,
        }, elapsed);
      } catch {
        // Non-throwing — session_end must not crash
      } finally {
        // Clean up globalThis registration
        (globalThis as any)[BRIDGE_KEY] = undefined;
        // Close DB
        closeDatabase(bctx.db);
      }
    });
  } catch {
    // activate() must not throw — OpenClaw plugin load should degrade gracefully
  }
}
```

Key design decisions:
- DB opened once in `activate()`, closed in `session_end` (persistent lifecycle per Architecture Section 3.3)
- `bctx.sessionId` starts as empty string, gets set by `onInit` when the session actually starts
- `globalThis[BRIDGE_KEY]` set to `undefined` (not `delete`) in cleanup to avoid issues with Symbol-keyed property deletion
- Entire `activate()` body wrapped in try/catch for graceful degradation
- Session end logic mirrors CC's `session-end.ts` but without token gauge (no transcript access on OpenClaw, and we don't have ctx.getContextUsage() in the session_end hook since it comes via api.registerHook, not via a Pi SDK context)
