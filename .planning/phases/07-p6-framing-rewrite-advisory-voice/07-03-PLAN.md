# Plan 07-03 — Behavioral A/B scaffold + phase close

## Goal

Ship the loose 1-week behavioral A/B scaffold (CONTEXT.md hard gate:
*"behavioral A/B writeup committed before phase close"*), update STATE /
ROADMAP / REQUIREMENTS to reflect Phase 7 closure, and write the phase
SUMMARY. The 1-week soak begins on the merge of this commit; the user fills
in the end-of-week scoring directly into `07-BEHAVIORAL-AB.md` later.

## Why a separate plan

CONTEXT.md treats the A/B writeup as a hard gate, not a side-effect of the
rewrite or the gate run. Splitting lets the scaffold ship cleanly with no
test-suite coupling and makes the phase-close commit auditable as a single
atomic boundary.

## 1. Pre-merge baseline notes (filled in at merge)

What pre-Phase-7 agent behavior felt like, captured at moment of merge so
end-of-week comparison is anchored:

- *Imperative-frame surfaces seen frequently:*
  - `WARNING:` prefixes on experience patterns
  - `**Correct approach:** {lesson}` per pattern
  - `Apply them proactively — they are always relevant` footer on Proven Principles
  - `STOP NOW` / `Wrap up` / `Do NOT start` on context-pressure zones
- *How agent behavior felt under those framings:*
  - Tendency to treat surfaced learnings as rules to follow rather than past
    experience to reason with
  - Risk of rule-following on borderline cases where the lesson didn't quite apply
  - Pressure-zone messages produced abrupt task-abort behavior even when the
    user wanted continuation
- *What the rewrite should subjectively shift:*
  - Agent reasoning *from* prior observation rather than *under* a rule
  - Borderline cases handled as judgment calls, not rule-misses
  - Pressure-zone messages produce graceful handoff intent without forcing
    abrupt abort

## Rollback

If end-of-week verdict is FAIL with active regressions, rollback path is:
1. `git revert` Plan 07-01's commit
2. Update ROADMAP / STATE to mark Phase 7 as `[~] partial-corrective-pending`
3. Schedule a Phase 7-corrective with feedback from the verdict

If verdict is *extend*: no rollback; just extend the soak window 3-7 days
and refile the verdict. Phase 7.5 can still proceed in parallel during the
extension window since it depends on framing being *locked*, not on the
verdict being *signed*.
