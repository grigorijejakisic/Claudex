**src/core/observations.ts** — Plain functions, `db: Database` as first param (per user decision).

`insertObservation(db, obs: { session_id, project, tool_name, category, title, content, importance, files_modified })`: INSERT into observations table. The `files_modified` param accepts `string[]` and is serialized to JSON. Returns the inserted row id. Validate category against the allowed enum values.

`getObservationsByProject(db, project: string, opts?: { limit?: number, includeDeleted?: boolean })`: SELECT from observations WHERE project = ? AND deleted_at_epoch IS NULL (unless includeDeleted). ORDER BY timestamp_epoch DESC. LIMIT defaults to 100.

`getObservationById(db, id: number)`: SELECT single observation by id.

`searchObservations(db, query: string, project: string, opts?: { limit?: number })`: FTS5 search with BM25 temporal re-ranking. SQL approach:
```sql
SELECT o.*, bm25(observations_fts) as bm25_rank
FROM observations_fts fts
JOIN observations o ON o.id = fts.rowid
WHERE observations_fts MATCH ?
  AND o.project = ?
  AND o.deleted_at_epoch IS NULL
ORDER BY bm25(observations_fts) -- BM25 initial ranking
LIMIT ?
```
Then in JS, apply temporal re-ranking per user decision:
`finalScore = bm25Rank * Math.exp(-ageDays / 30)` where `ageDays = (Date.now()/1000 - timestamp_epoch) / 86400`.
Re-sort by finalScore (lower is better for bm25, so multiply and keep sign convention).
Return results sorted by temporal-adjusted relevance.

`softDeleteObservation(db, id: number)`: UPDATE SET deleted_at_epoch = unixepoch() WHERE id = ?

`incrementAccessCount(db, id: number)`: UPDATE SET access_count = access_count + 1, last_accessed_at_epoch = unixepoch() WHERE id = ?

All query functions filter by project for scope isolation (QUAL-04).

**src/observability/telemetry.ts** — Plain functions, `db: Database` as first param:

`emitTelemetry(db, sessionId: string, eventKind: EventKind, detail: TelemetryDetail, latencyMs?: number): void` — INSERT into telemetry table. JSON.stringify the detail object. **Non-throwing**: entire function wrapped in try/catch that silently swallows errors. Fast INSERT in WAL mode.

`queryTelemetry(db, opts: { sessionId?: string, eventKind?: EventKind, limit?: number }): TelemetryRow[]` — SELECT with optional filters. ORDER BY timestamp_epoch DESC. Parse detail JSON back to typed object.

`pruneTelemetry(db, opts?: { retentionDays?: number, retainErrorCount?: number }): number` — Implements Architecture Section 10c retention:
1. Delete rows older than retentionDays (default 7) EXCEPT error events
2. For error events: keep last retainErrorCount (default 1000) regardless of age
3. DELETE FROM telemetry WHERE timestamp_epoch < cutoff AND event_kind != 'error'
4. DELETE FROM telemetry WHERE event_kind = 'error' AND id NOT IN (SELECT id FROM telemetry WHERE event_kind = 'error' ORDER BY timestamp_epoch DESC LIMIT 1000)
Returns number of rows pruned.

Defaults come from DEFAULT_CONFIG.observability (retention_days=7, retain_error_count=1000).
