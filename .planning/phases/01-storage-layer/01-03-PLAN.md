All modules: plain functions, `db: Database` as first param. Non-throwing where appropriate. All queries that return data filter by project scope (QUAL-04).

**src/core/sessions.ts:**

`createSession(db, session: { session_id, scope?, project?, cwd?, source? }): void` — INSERT into sessions table.

`getSession(db, sessionId: string): SessionRow | undefined` — SELECT by session_id.

`endSession(db, sessionId: string, status: 'completed' | 'failed'): void` — UPDATE SET status = ?, ended_at_epoch = unixepoch() WHERE session_id = ?

`getActiveSession(db, project?: string): SessionRow | undefined` — SELECT WHERE status = 'active'. If project provided, filter by project. ORDER BY created_at_epoch DESC LIMIT 1.

`incrementObservationCount(db, sessionId: string): void` — UPDATE SET observation_count = observation_count + 1 WHERE session_id = ?

**src/core/decisions.ts:**

`insertDecision(db, decision: { session_id, project?, content, source, fingerprint }): number | null` — INSERT OR IGNORE (UNIQUE on session_id+fingerprint handles dedup). Returns id if inserted, null if duplicate. project defaults to '__global__'.

`getDecisionsBySession(db, sessionId: string): DecisionRow[]` — SELECT WHERE session_id = ? ORDER BY timestamp_epoch DESC.

`getDecisionsByProject(db, project: string): DecisionRow[]` — SELECT WHERE project = ? ORDER BY timestamp_epoch DESC.

`resetSessionDecisions(db, sessionId: string): number` — DELETE WHERE session_id = ?. Returns count deleted. Used in beforeCompact transaction.

**src/core/learnings.ts:**

`upsertLearning(db, learning: { project?, agent_id?, fingerprint, content }): void` — INSERT ... ON CONFLICT(project, agent_id, fingerprint) DO UPDATE SET promotion_count = promotion_count + 1, last_promoted_epoch = unixepoch(), updated_at_epoch = unixepoch(). Defaults: project='__global__', agent_id='default'.

`getLearningsByProject(db, project: string, opts?: { limit?: number }): LearningRow[]` — SELECT WHERE project = ? OR project = '__global__' ORDER BY promotion_count DESC. Default limit 50 (per config max_per_project).

`getTopLearnings(db, project: string, count?: number): LearningRow[]` — Same as getLearningsByProject but defaults to count=10 (per config surface_count). For assembly injection.

All modules: plain functions, `db: Database` as first param. Non-throwing. Scope-aware queries.

**src/core/thread.ts:**

`upsertThreadState(db, state: { session_id, topic?, summary?, key_exchanges?: Array<{role: string, gist: string}> }): void` — INSERT OR REPLACE into thread_state. JSON.stringify key_exchanges. updated_at_epoch = unixepoch().

`getThreadState(db, sessionId: string): ThreadStateRow | undefined` — SELECT by session_id. Parse key_exchanges JSON.

`resetThreadState(db, sessionId: string): void` — DELETE WHERE session_id = ?. Used in beforeCompact transaction.

**src/core/pressure.ts:**

`updatePressureScore(db, filePath: string, project: string, rawPressureIncrement: number): void` — INSERT ... ON CONFLICT(file_path, project) DO UPDATE SET raw_pressure = raw_pressure + ?, last_touched_epoch = unixepoch(). If resulting raw_pressure > threshold (e.g., 0.5), set temperature = 'HOT', else 'COLD'.

`getPressureByProject(db, project: string): PressureRow[]` — SELECT WHERE project = ? ORDER BY raw_pressure DESC.

`getHotFiles(db, project: string, limit?: number): PressureRow[]` — SELECT WHERE project = ? AND temperature = 'HOT' ORDER BY raw_pressure DESC LIMIT ?.

`decayPressure(db, project: string, decayRate?: number): number` — UPDATE pressure_scores SET raw_pressure = raw_pressure * (1 - decay_rate) WHERE project = ?. Then UPDATE temperature = 'COLD' WHERE raw_pressure < 0.1. Returns rows affected.

**src/core/checkpoint-tracking.ts:**

`getCheckpointTracking(db, sessionId: string): CheckpointTrackingRow | undefined` — SELECT by session_id.

`updateCheckpointTracking(db, sessionId: string, observationCount: number): void` — INSERT OR REPLACE into checkpoint_tracking, setting observation_count, updated_at_epoch = unixepoch().

`markPostCompactPending(db, sessionId: string): void` — UPDATE SET post_compact_pending = 1 WHERE session_id = ?. If no row, INSERT with post_compact_pending = 1.

`clearPostCompactPending(db, sessionId: string): void` — UPDATE SET post_compact_pending = 0 WHERE session_id = ?.

`recordThresholdHit(db, sessionId: string, threshold: number): void` — Read current thresholds_hit JSON array, append threshold, write back. UPDATE SET thresholds_hit = ?, updated_at_epoch = unixepoch().
