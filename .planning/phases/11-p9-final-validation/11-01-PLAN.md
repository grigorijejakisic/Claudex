The 5-dimension rubric from CONTEXT.md lines 56-61 (Phase 4.1 design):

1. **Parsing (20 points)**: parse the file with the same MEMORY.md parser used in production (`src/angel/memory-md-writer.ts` or wherever the live parser lives — discover via grep). Zero parsing errors → 20pts. Any parse error → 0pts (hard fail dimension).

2. **Project-specific pointers (20 points)**: count pointers (markdown link references in `## Recent Threads`, `## Active Projects`, and `## How to Query` sections). A pointer is "project-specific" if its target identifier (file path, artifact id, session label) contains the project's slug or refers to a project-local file. Score = `min(20, 20 * (project_specific / total_pointers))`. If `total_pointers === 0` → 0pts.

3. **Topics not session-IDs (20 points)**: in `## Recent Threads`, count entries whose visible label looks like a topic (contains alphabetic words ≥3 chars long, e.g. "Phase 11 final validation") vs entries that are bare session IDs (UUID-shaped or `session-XXXXXXX` only). Score = `min(20, 20 * (topic_labeled / total_threads))`. If `total_threads === 0` → 20pts (no penalty for empty section).

4. **Pointer density (20 points)**: `pointer_count / nonblank_line_count`. ≥0.10 → 20pts. Linear from 0.05 → 10pts to 0.10 → 20pts. <0.05 → 0pts.

5. **Handoff freshness (20 points)**: read MEMORY.md `## Handoff` section. If it says "No active handoff" AND `context/handoffs/ACTIVE.md` is missing OR has frontmatter `status: archived` → 20pts (consistent). If MEMORY.md says "No active handoff" but ACTIVE.md has `status: active` → 0pts (drift). If MEMORY.md links to a handoff AND ACTIVE.md frontmatter `status: active` → 20pts. Other combinations → 10pts (warn).

Total = sum (max 100). Pass threshold per CONTEXT line 17: ≥80.

```ts
export interface MemoryQualityScore {
  project: string;            // project slug (e.g. "claudex-v3")

  total: number;              // 0–100
  pass: boolean;              // total >= 80
  dimensions: {
    parsing: { score: number; max: 20; details: string };
    projectSpecific: { score: number; max: 20; total: number; specific: number };
    topicsNotSessionIds: { score: number; max: 20; total: number; topicLabeled: number };
    pointerDensity: { score: number; max: 20; ratio: number; nonblankLines: number; pointers: number };
    handoffFreshness: { score: number; max: 20; details: string };
  };
}
```

Create `src/benchmark/memory-quality/cli.ts`:

```ts
#!/usr/bin/env bun
import { ACTIVE_PROJECTS } from './projects';
import { scoreMemoryFile } from './scorer';

async function main() {
  const args = process.argv.slice(2);
  const jsonOutput = args.includes('--json');

  const results = ACTIVE_PROJECTS.map(p => {
    if (!fs.existsSync(p.memoryPath)) return { project: p.slug, missing: true };
    return scoreMemoryFile(p.memoryPath, { activeHandoffPath: p.activeHandoffPath });
  });

  const allPass = results.every(r => 'pass' in r ? r.pass : false);
  const aggregate = results.filter(r => 'total' in r).reduce((sum, r) => sum + r.total, 0)
                     / results.filter(r => 'total' in r).length;

  if (jsonOutput) {
    console.log(JSON.stringify({ gated: allPass, aggregate, results }, null, 2));
  } else {
    // pretty table: project | score | pass
    // ...
  }

  process.exit(allPass ? 0 : 1);
}

main();
```
