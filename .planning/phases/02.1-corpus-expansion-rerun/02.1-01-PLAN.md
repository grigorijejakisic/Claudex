<objective>
Replace Phase 2's two-tier `corpus_origin` (`phase1_organic` | `v4_backfill`) with the three-tier phase-anchored scheme locked in CONTEXT.md decision 1c:

- `v4_backfill` — unchanged.
- `phase1_organic_pre_phase2_close` — `provenance='organic'` AND `ts_epoch <= PHASE2_CLOSE_TS_EPOCH` (the timestamp Phase 2's measurement was generated, sourced from `.planning/phases/02-multi-modal-index-seeds-density-check/02-results.json` `harness.ts_epoch`).
- `phase1_organic_post_phase2_close` — `provenance='organic'` AND `ts_epoch > PHASE2_CLOSE_TS_EPOCH`.

Phase-anchoring (NOT date-anchoring) is non-negotiable per CONTEXT.md decision 1c: if 2.1 is re-run in a week, the partition stays meaningful. Date-anchored tags would require re-stamping, breaking the bound-experience invariant.

Idempotent re-backfill: running `bun run src/benchmark/episodic-density/cli.ts backfill` twice produces identical sidecar state. New organic events accumulated since the last run are added; existing rows are never rewritten (CONTEXT.md decision 1a caveat — Phase 2.1's corpus delta over Phase 2 is small absent the labeler relaxation in Plan 02.1-02; 1a is supplementary to 02.1-02's primary lever, NOT a substitute).

This plan adds NO new index modality, NO new measurement methodology — only the corpus_origin widening and the phase-anchor constant. CONTEXT.md "what's NEW vs Phase 2" boundary applies: corpus expansion strategy + reporting layer only.
