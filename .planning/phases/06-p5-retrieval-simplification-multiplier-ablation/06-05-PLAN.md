# Plan 06-05 — RETR-03 (RIF + spread retained) + RETR-04 (MCP surface unchanged) verification

**Wave:** 4 (depends on the deletion landing in W3 and the telemetry surface in W4).
**Goal:** Lock down what must NOT change.

## Requirements addressed
- **RETR-03** — Keep RIF suppression and spread activation, both light and measurably useful for dedup.
- **RETR-04** — MCP surface unchanged: `claudex_search`, `claudex_recall`, `claudex_events`, `claudex_store`, `claudex_message`.

## must_haves
- A new integration test asserts that `applyRetrievalInducedSuppression` and `spreadActivation` are both still present, callable, and behaviorally equivalent to their Phase 5 form.
- A "measurably useful for dedup" check exists: an A/B test where running RIF on a query with 5 near-duplicate candidates produces a measurable activation_score decrement on the non-selected duplicates (the existing test in `hybrid-retrieval.test.ts` likely covers this — extend, don't duplicate).
- A new integration test exercises every MCP tool (`claudex_search`, `claudex_recall`, `claudex_events`, `claudex_store`, `claudex_message`) and asserts response **shape** equality against a Phase-5-era fixture. Ordering may shift in `claudex_search`; keys must not.

<steps>
1. Create `src/tests/integration/phase-6-rif-spread-retained.test.ts`. Look at `src/tests/core/hybrid-retrieval.test.ts` for the existing RIF/spread test patterns and base on those.
2. Two scenarios:
   - **RIF dedup:** seed 6 artifacts where 5 are near-dupes by content. Build rrfScores artificially placing all 6 above `RIF_MIN_RRF`. Mark 1 selected. Call `applyRetrievalInducedSuppression`. Assert the 5 non-selected got `activation_score -= 0.03` clamped at 0.1.
   - **Spread:** seed an artifact A linked to B and C in `artifact_links` with strength 1.0. Set A's activation to 1.0. Call `spreadActivation(db, A.id)`. Assert B and C got `activation_score += 0.3 * 1.0 * 1.0 = 0.3`.
3. Add a regression-canary assertion: print the SPREAD_FACTOR, RIF_DECREMENT, RIF_ACTIVATION_FLOOR constants from the module via TS reflection (not exported) — instead, assert via behavior (delta = 0.3, decrement = 0.03, floor = 0.1).
</steps>
</task>
