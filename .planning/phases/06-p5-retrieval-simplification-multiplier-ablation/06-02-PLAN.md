# Plan 06-02 — Per-multiplier ablation runs + structured results

**Wave:** 2 (depends only on 06-01).
**Goal:** produce evidence — one A/B per multiplier — that determines W3 deletions.

## Requirements addressed
- RETR-05 — per-multiplier ablation BEFORE bulk delete; results committed.

## must_haves
- `06-MULTIPLIER-ABLATION.md` exists at the phase directory with a structured per-multiplier results table.
- For every multiplier in `MULTIPLIERS_TO_ABLATE`, the document records:
  - The pass rate when that multiplier is **enabled** (baseline reference).
  - The pass rate when that multiplier is **disabled** (and all others enabled).
  - The delta in percentage points.
  - A verdict: `KEEP` (delta >1pp or statistically meaningful degradation) or `DROP` (delta ≤1pp).
- Edge-case verdict (improves one Vesna category, degrades another) recorded as `KEEP-WITH-TRADE-OFF`.
- Baseline pass rate (all multipliers enabled) ≥ Phase 5/5.5 most recent Vesna result (currently 100% on the 4-probe proxy set; expect this number to drop with the expanded probe set, but the bar is still ≥80%).
- The run JSON files persist under `runs/` for audit reproducibility.
