## Migration deployment plan

The migration takes effect on Angel's first heartbeat after deploy that visits each project. The Plan 09 live-fire gate will exercise the writer end-to-end.

For Lacuna/Oracle/Nexus specifically (existing hand-curated files), once Angel runs after this code is in production:
- Heartbeat queries for active projects, calls `curateMemoryMd` on each
- For each of these 3 projects, `existing` content has no marker (legacy hand-curated state) → migration branch fires
- Output: top sentinel + managed section + fresh `<!-- USER EDITABLE -->` + `## User Notes` (or existing `## User Notes` if Nexus's `# Nexus Project Memory Index` is preserved as-is) + the 4-5 pointer lines preserved verbatim
- Subsequent heartbeat ticks see the marker and use the standard sentinel-checked path → no further changes unless managed section input changes
