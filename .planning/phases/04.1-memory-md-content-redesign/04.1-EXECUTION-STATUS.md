   projection list omits `data` from view columns. Direct UPDATE on the view
   for JSON-column changes is not supported by the INSTEAD OF triggers. Use
   the sidecar table approach (Plan 07).

2. **TARGET_VERSION bump 16→18 cascade** — required updating ~6 existing
   tests asserting `user_version=16`. Also required adding a V17-views-active
   gate in initializeSchema (post-V17 path) so SCHEMA_V3's CREATE INDEX
   statements don't trip "views may not be indexed" on fully-migrated DBs.
   See `src/core/migrations.ts:204+`.

3. **Demotion-prevention floor** — the `if (currentUv < 16) db.pragma('user_version = 16')`
   at line 234 silently demoted V17 DBs back to 16; raised to `< 18` to
   match new TARGET_VERSION. Bug originally fixed in 04-07; now widened.

4. **Existing memory-md-writer tests asserted `## Entities` content** —
   Phase 4.1 dropped that section. Updated 3 tests to assert ABSENCE of
   Entities/Recent Threads + PRESENCE of Lessons. One test (user-tail
   preservation) needed its trigger changed from `seedEntities` to
   `seedActiveProjects` since entities no longer drive a managed-section
   diff.

5. **Heartbeat test third-tick re-curation** — same fix as above. The
   trigger to drive a managed-section diff was switched from entity-seed

6. **Bun cannot load better-sqlite3** — soak script must run via
   `node dist/scripts/phase-4-1-soak.cjs` (compiled), not via

   build.ts entry-point list updated.
