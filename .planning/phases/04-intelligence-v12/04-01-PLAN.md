**src/embeddings/cosine.ts** — Pure math function, no dependencies. Non-throwing.

`cosineSimilarity(a: number[], b: number[]): number` — Compute cosine similarity between two vectors:
- Dot product / (magnitude_a * magnitude_b)
- Return 0.0 if either vector has zero magnitude (avoid division by zero)
- Return 0.0 if vectors have different lengths
- Return value range: -1.0 to 1.0 (normalized embeddings typically 0.0 to 1.0)
- Non-throwing (return 0 on error)

**src/embeddings/embedding-provider.ts** — Ollama nomic-embed-text client. Non-throwing class.

```typescript
export class EmbeddingProvider {
  private baseUrl: string;
  private model: string;
  private available: boolean | null; // null = not yet checked

  constructor(config?: { baseUrl?: string; model?: string })
}
```

`constructor(config?)` — Initialize with optional config overrides:
- `baseUrl` defaults to `'http://localhost:11434'`
- `model` defaults to `'nomic-embed-text'`
- `available` starts as `null` (lazy check)

`async isAvailable(): Promise<boolean>` — Health check:
- `fetch(baseUrl + '/api/tags')` with 3000ms timeout (AbortController)
- Parse response JSON, check `models` array contains a model matching `this.model`
- Cache result in `this.available` (avoids re-checking every call)
- Return false on any error (network, timeout, parse)
- Non-throwing

`async embed(text: string): Promise<number[] | null>` — Compute embedding:
- If `this.available === false`, return null immediately (skip HTTP)
- If `this.available === null`, call `isAvailable()` first
- `fetch(baseUrl + '/api/embed', { method: 'POST', body: JSON.stringify({ model, input: text }) })` with 5000ms timeout
- Parse response: `response.json()` → `{ embeddings: [number[]] }` → return `embeddings[0]`
- Return null on any error (network, timeout, parse, model not loaded)
- Non-throwing

`resetAvailability(): void` — Clear cached availability (for testing or re-check):
- Set `this.available = null`

**src/embeddings/templates.ts** — Precomputed template embeddings for decision classification. Non-throwing.

```typescript
export interface DecisionTemplates {
  positive: Map<string, number[]>;  // template text -> embedding
  negative: Map<string, number[]>;  // template text -> embedding
}
```

`async initTemplates(provider: EmbeddingProvider): Promise<DecisionTemplates | null>` — Precompute template embeddings:
- 5 positive templates (from Architecture 6.1):
  - "We decided to use X instead of Y"
  - "The approach is to implement X"
  - "Confirmed: we will proceed with X"
  - "Rejected Y in favor of X"
  - "Architecture decision: X for the storage layer"
- 4 negative templates (from Architecture 6.1):
  - "Let me read the file"
  - "I'll check that for you"
  - "Looking at the code now"
  - "Running the tests"
- For each template: `provider.embed(template)` → store in Map
- If provider unavailable or any embedding returns null: return null (entire templates object)
- Non-throwing (return null on error)

`classifyDecision(candidateEmb: number[], templates: DecisionTemplates): number` — Classify a candidate embedding:
- Compare candidateEmb against all positive templates: `cosineSimilarity(candidateEmb, posEmb)` for each
- `maxPositive = Math.max(...positiveSimilarities)`
- Compare candidateEmb against all negative templates: `cosineSimilarity(candidateEmb, negEmb)` for each
- `maxNegative = Math.max(...negativeSimilarities)`
- Return `maxPositive - maxNegative` (confidence score)
- Positive score = more like a decision, negative = more like filler
- Non-throwing (return 0 on error)
