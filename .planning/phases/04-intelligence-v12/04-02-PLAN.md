`TopicShiftDetector` class — Maintains sliding window of recent prompt embeddings:

```typescript
export class TopicShiftDetector {
  private provider: EmbeddingProvider | null;
  private recentPromptEmbeddings: number[][];  // sliding window of last 3
  private topicEmbeddingCache: { topic: string; embedding: number[] } | null;

  constructor(provider: EmbeddingProvider | null)
}
```

`constructor(provider)` — Initialize:
- Store provider (null = no embeddings, Layer 3 fallback only)
- Initialize recentPromptEmbeddings as empty array
- Initialize topicEmbeddingCache as null

`async detectTopicShift(params: { prompt: string; db: Database; sessionId: string; config?: { topicShiftThreshold?: number; topicShiftWindow?: number } }): Promise<TopicShiftResult>` — Main detection:

**Layer 1: Explicit pivot signals (always checked first)**
- Regex: `^(now let's|next[,:]|switch to|moving on|let's work on|different topic|new task|back to|forget that|actually[,:]?\s*(?:let's|can we|I need))/i` on `prompt.trim()`
- If match: infer new topic via `inferTopic(prompt)`, return `{ shifted: true, newTopic, previousTopic: thread.topic, confidence: 1.0, method: 'explicit' }`

**Layer 2: Embedding cosine similarity (when provider available)**
- Get current topic from DB: `getThreadState(db, sessionId)`. If no topic, return `{ shifted: false }`.
- Embed topic (with cache): if `topicEmbeddingCache?.topic === thread.topic`, reuse cached embedding. Otherwise `provider.embed(thread.topic)` and cache.
- Embed prompt: `provider.embed(prompt)`. If null (Ollama failed mid-call), fall through to Layer 3.
- Compute similarity: `cosineSimilarity(topicEmb, promptEmb)`
- Sliding window avgRecent:
  - Compare promptEmb against each embedding in `recentPromptEmbeddings` (last 3 user prompts)
  - `avgRecent = average(similarities)` or `similarity` if window empty
- Push promptEmb to `recentPromptEmbeddings`, trim to last 3 (configurable via `config.topicShiftWindow`, default 3)
- Shift detection: `similarity < threshold (default 0.35) AND avgRecent < 0.40`
  - If shift: infer new topic, invalidate topicEmbeddingCache, return shifted result with `method: 'embedding'`
  - If no shift: return `{ shifted: false }`

**Layer 3: Keyword Jaccard fallback (when no embeddings)**
- Get current topic from DB. If no topic, return `{ shifted: false }`.
- `keywordJaccard(thread.topic, prompt)` — reuse from semantic-dedup.ts
- If `overlap < 0.15`: infer new topic, return shifted result with `method: 'jaccard'`
- Otherwise: return `{ shifted: false }`

`inferTopic(text: string): string` — Extract new topic from pivot prompt:
- Reuse same logic as `extractTopic` from thread-tracker.ts (first sentence + stop-word removal)
- Import or inline the same approach (prefer importing `extractTopic` from thread-tracker.ts if it's exported)

`clearCache(): void` — Clear topic embedding cache and recent prompt window (for session reset).

**src/intelligence/enrichment.ts** — LLM enrichment module. Non-throwing.

```typescript
export interface EnrichmentProvider {
  type: 'ollama' | 'openclaw-native';
  model?: string;   // Ollama model name (e.g., "glm-4.7-flash:q4_K_M")
  baseUrl?: string;  // Ollama base URL
}

export interface CheckpointData {
  topic?: string;
  task?: string;
  status?: string;
  decisions?: string[];
  open_items?: string[];
  learnings?: string[];
  summary?: string;
  key_exchanges?: Array<{ role: string; gist: string }>;
}
```

`async detectEnrichmentProvider(config: { baseUrl?: string; model?: string; provider?: string }, capabilities: RuntimeCapabilities): Promise<EnrichmentProvider | null>` — One-time detection at core init:

1. Try Ollama first (works for both CC and OpenClaw):
   - `fetch(baseUrl + '/api/tags')` with 3000ms timeout
   - Parse response, check `models` array
   - If `model === 'auto'`: pick smallest available model by size (`models.sort((a, b) => a.size - b.size)[0]`)
   - If specific model: check it's in the list
   - Return `{ type: 'ollama', model: selectedModel, baseUrl }`
2. Try OpenClaw native (only if `capabilities.hasFullMessageHistory` is true):
   - Return `{ type: 'openclaw-native' }`
3. Return null (no enrichment available — heuristic checkpoint is canonical)

Config overrides:
- If `config.provider === 'ollama'`: skip step 2 (force Ollama only)
- If `config.provider === 'native'`: skip step 1 (force OpenClaw only)
- If `config.provider === 'auto'` (default): try both in order

Non-throwing (return null on error).

`async enrichCheckpoint(data: CheckpointData, provider: EnrichmentProvider): Promise<Partial<CheckpointData> | null>` — Call LLM for enrichment:

- Build prompt per Architecture 6.4 (~2.7k tokens input, 800 max output):
```
You are reviewing a session checkpoint. Refine the following heuristic data.
For each field, keep what's accurate, fix what's imprecise, remove what's noise.
Do NOT invent — only refine what's given.

Current checkpoint:
- Topic: {topic}
- Task: {task}
- Status: {status}
- Decisions: {decisions as JSON array}
- Open items: {open_items as JSON array}
- Learnings: {learnings as JSON array}
- Thread summary: {summary}
- Key exchanges: {key_exchanges as JSON array}

Return JSON with the same fields. Any field you don't want to change, return as-is.
```

- If `provider.type === 'ollama'`:
  - `fetch(provider.baseUrl + '/v1/chat/completions', { method: 'POST', body: JSON.stringify({ model: provider.model, messages: [{ role: 'user', content: prompt }], max_tokens: 800, temperature: 0 }) })` with config timeout (default 10000ms)
  - Parse response: `response.json()` → `choices[0].message.content`
  - Parse content as JSON → return as `Partial<CheckpointData>`
- If `provider.type === 'openclaw-native'`:
  - Return null for now (actual native API wiring deferred to Phase 9)

- Return null on any error (HTTP, JSON parse, timeout). Non-throwing.

`mergeEnrichment(heuristic: CheckpointData, enriched: Partial<CheckpointData>): CheckpointData` — Pure safety-net merge per Architecture 6.4:

- Start with `result = { ...heuristic }`
- For array fields (`decisions`, `open_items`, `learnings`):
  - If `enriched[field]` has entries:
    - Accept enriched entries as primary: `result[field] = [...enriched[field]]`
    - Find uncovered heuristic entries: heuristic entries NOT in enriched set
      - Normalize check: `enrichedSet = new Set(enriched[field].map(normalizeForDedup))`
      - Also check semantic duplicates: `!enriched[field].some(e => isDuplicate(h, e))`
    - Append uncovered entries to result (LLM missed them — safety net preserves them)
- For string fields (`topic`, `summary`, `task`, `status`):
  - Prefer enriched if non-empty: `if (enriched[field]) result[field] = enriched[field]`
- For `key_exchanges`: prefer enriched if array is non-empty
- Return merged result

Non-throwing (return heuristic unchanged on error).
