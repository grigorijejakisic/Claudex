# Plan 08-03 — Decision lock + phase close

## Goal

Read the verdict from `08-rl-ablation-summary.json` (produced by Plan 08-02)
and commit it to `context/specs/V4_RL_ABLATION.md`. Phase 9 reads this file
to schedule (or skip) sub-phase 9.8 (the actual RL stack deletion). Update
STATE / ROADMAP / REQUIREMENTS to mark Phase 8 closed and link the decision.

CONTEXT.md success criteria #3 and #4 require *the decision is locked in
writing before Phase 9 begins*. This plan ships that lock.

## Why a separate plan from the harness

CONTEXT.md treats the decision lock as a hard gate. Splitting it from the
A/B harness lets the lock be written even if the harness needs a re-run
(e.g., variance prompts a fourth trial). It also makes the phase-close
commit auditable as a single boundary that cites a specific JSON artifact
hash.
