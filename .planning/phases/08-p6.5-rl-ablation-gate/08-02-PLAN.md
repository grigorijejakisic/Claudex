# Plan 08-02 — A/B Vesna probe harness (ABL-02)

## Goal

Run the Vesna probe suite under `CLAUDEX_DISABLE_RL_SCORING=1` (B) vs unset
(A), three trials each condition, on the existing in-process probe set.
Aggregate per-category, mean + range, write the summary to JSON. The summary
JSON is the single artifact downstream Plan 08-03 reads to make the decision.

The harness asserts the gate fired (telemetry counter > 0 in flagged trials,
== 0 in baseline trials) — a misimplemented gate that silently no-ops would
be caught here, not at decision time.

## Probe set composition (per RESEARCH.md)

CONTEXT.md `<decisions>` accepts "minimum 10 probes from existing test files".
This plan stitches **14 probes** across **5 of CONTEXT.md's 6 categories**:

| Source | Probes | Categories | Mapped to CONTEXT.md category |
|---|---:|---|---|
| `phase-6-multiplier-ablation.test.ts` PROBES array | 11 | lesson(4), entity(3), constraint(2), handoff(2) | lesson application, entity recall, constraint recall, handoff pickup |
| `phase-6-5-cross-project-vesna.test.ts` 3 probes | 3 | cross-project(3) | cross-project |

Self-instrumented category (CONTEXT.md's 6th) has zero existing probes.
**Document this gap in the summary JSON** — Phase 10's full ~20-probe suite
is the future fill-in. Phase 8 is honest about what it can measure: 5 of 6
categories.

## Why three trials, not two

CONTEXT.md says 2-3, recommends 3. With N=14 probes the per-probe resolution
is `1/14 ≈ 7.1pp`. A 2pp gate is below probe resolution; the realized deltas
step at 7.1pp. Three trials catch trial-to-trial noise (e.g., a flaky probe
that flips on one trial only) without dramatically slowing the harness.

## Why import probes, not duplicate them

Both source files already export the probe data structure (Phase 6) or run
the probe E2E (Phase 6.5). The Phase 8 harness *reuses* — it does not fork.
This keeps the Phase 6 confound visible: if Phase 6 probes show 0pp under
the env-var gate too, that's the same evidence Phase 6's `multiplierFlags`
ablation produced, validated through a different gate path.

```ts
async function runOneTrial(
  trial: number,
  condition: 'baseline' | 'flagged',
): Promise<TrialResult> {
  // Set or clear the env var for this trial. Note: the env var is read at
  // call time inside computeQMultiplier — flipping it here propagates.
  if (condition === 'flagged') {
    process.env.CLAUDEX_DISABLE_RL_SCORING = '1';
  } else {
    delete process.env.CLAUDEX_DISABLE_RL_SCORING;
  }

  resetRlScoringDisabledCounter();

  const perProbe: ProbeResult[] = [];

  // Phase 6 probes (11)
  for (const probe of PHASE_6_PROBES) {
    const outcome = runPhase6Probe(probe, {}); // no multiplierFlags — we test the env var, not the flag map
    perProbe.push({
      probeId: probe.id,
      flavor: probe.flavor as Flavor,
      passed: outcome.passed,
    });
  }

  // Phase 6.5 probes (3)
  for (const probe of CROSS_PROJECT_PROBES) {
    const outcome = await runCrossProjectProbe(probe);
    perProbe.push({
      probeId: probe.id,
      flavor: 'cross-project',
      passed: outcome.passed,
    });
  }

  const passCount = perProbe.filter(p => p.passed).length;
  const total = perProbe.length;

  const perCategory: TrialResult['perCategory'] = Object.fromEntries(
    FLAVORS.map(f => [f, { passed: 0, total: 0, rate: 0 }])
  ) as TrialResult['perCategory'];
  for (const r of perProbe) {
    perCategory[r.flavor].total += 1;
    if (r.passed) perCategory[r.flavor].passed += 1;
  }
  for (const f of FLAVORS) {
    perCategory[f].rate = perCategory[f].total === 0 ? 0 : perCategory[f].passed / perCategory[f].total;
  }

  const rlGateFireCount = getRlScoringDisabledCount();

  return { trial, passCount, total, passRate: passCount / total, perCategory, perProbe, rlGateFireCount };
}

async function runCondition(condition: 'baseline' | 'flagged'): Promise<ConditionResult> {
  const trials: TrialResult[] = [];
  for (let i = 1; i <= TRIALS; i++) {
    trials.push(await runOneTrial(i, condition));
  }
  const passRates = trials.map(t => t.passRate);
  const meanPassRate = passRates.reduce((a, b) => a + b, 0) / passRates.length;
  const rangeMin = Math.min(...passRates);
  const rangeMax = Math.max(...passRates);

  const meanPerCategory = Object.fromEntries(
    FLAVORS.map(f => {
      const rates = trials.map(t => t.perCategory[f].rate);
      return [f, rates.reduce((a, b) => a + b, 0) / rates.length];
    })
  ) as Record<Flavor, number>;

  return { condition, trials, meanPassRate, rangeMin, rangeMax, meanPerCategory };
}
```

```ts
function computeSummary(baseline: ConditionResult, flagged: ConditionResult): AblationSummary {
  const deltaPp = (flagged.meanPassRate - baseline.meanPassRate) * 100;
  const perCategoryDeltaPp = Object.fromEntries(
    FLAVORS.map(f => [f, (flagged.meanPerCategory[f] - baseline.meanPerCategory[f]) * 100])
  ) as Record<Flavor, number>;

  // Range-aware: worst-case where flagged-mean is compared to baseline-max.
  // CONTEXT.md `<specifics>`: conservative-default at boundary, so report
  // the harsher number too — reviewer can decide which to honor.
  const rangeAwareDeltaPp = (flagged.meanPassRate - baseline.rangeMax) * 100;

  let verdict: AblationSummary['verdict'];
  if (Math.abs(deltaPp - (-2)) < 1e-6) {
    verdict = 'KEEP_CONSERVATIVE_DEFAULT';
  } else if (deltaPp >= -2) {
    verdict = 'DELETE_ALLOWED';
  } else {
    verdict = 'KEEP';
  }

  const notes: string[] = [];
  if (Math.min(...flagged.trials.map(t => t.rlGateFireCount)) === 0) {
    notes.push('WARNING: at least one flagged trial recorded zero gate fires — gate may not have intercepted the path');
  }
  if (baseline.trials.some(t => t.rlGateFireCount > 0)) {
    notes.push('WARNING: a baseline trial recorded gate fires — env var may have leaked across trials');
  }
  if (flagged.rangeMax - flagged.rangeMin > 0.15) {
    notes.push(`HIGH VARIANCE in flagged condition: range spans ${((flagged.rangeMax - flagged.rangeMin) * 100).toFixed(1)}pp across 3 trials`);
  }
  notes.push('Self-instrumented category not covered: 0 probes available pre-Phase-10');

  return {
    captured_at: new Date().toISOString(),
    probe_count: 14,
    trials_per_condition: TRIALS,
    decision_threshold_pp: -2 as const,
    baseline,
    flagged,
    delta_pp: deltaPp,
    per_category_delta_pp: perCategoryDeltaPp,
    range_aware_delta_pp: rangeAwareDeltaPp,
    verdict,
    notes,
  };
}

function writeSummary(summary: AblationSummary): void {
  const dir = path.resolve(
    process.cwd(),
    '.planning/phases/08-p6.5-rl-ablation-gate/runs',
  );
  fs.mkdirSync(dir, { recursive: true });
  fs.writeFileSync(path.join(dir, '08-rl-ablation-summary.json'), JSON.stringify(summary, null, 2));
}
```

The verdict is computed by aggregate `delta_pp` per CONTEXT.md. The

verdict — Plan 08-03's decision lock honors the contract verbatim.

## Risk + rollback

Risk: low for code, medium for verdict variance.

- **Code risk**: New file with no production callers. Test failures rollback
  via `git revert` on the atomic commit.
- **Verdict variance**: Three trials may disagree. The harness reports range
  + mean; the locked verdict is on `mean(flagged) − mean(baseline)`. If the
  range_aware_delta is much harsher (e.g., aggregate mean shows DELETE but
  worst-trial vs best-baseline shows KEEP), Plan 08-03's decision document
  must surface that asymmetry — not change the verdict (the contract is
  explicit on aggregate mean) but flag it for revisit-after-Phase-9.
