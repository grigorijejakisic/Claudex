# Plan 17-01: Artifact Relationship Graph

## Goal
Populate artifact_links via two-stage linking. Enable 2-hop graph walks as a 4th RRF channel in hybrid retrieval.

## Tasks

### Task 1: Bulk linking in Angel heartbeat
**File:** `src/angel/heartbeat.ts` (add new phase)

New function `linkUnlinkedArtifacts(db, project, batchSize = 20)`:
1. Query artifacts with embeddings but no outgoing links: `SELECT a.id, a.embedding FROM artifacts a LEFT JOIN artifact_links al ON a.id = al.source_id WHERE al.source_id IS NULL AND a.embedding IS NOT NULL AND a.project = ? LIMIT ?`
2. For each unlinked artifact, search Qdrant for top-5 similar artifacts (cosine > 0.6), excluding self
3. For each match, INSERT into artifact_links: `(source_id, target_id, 'related', cosine_score, now)`
4. Bidirectional: also insert `(target_id, source_id, 'related', cosine_score, now)` if not exists
5. Rate limit: run at most once per 5 minutes, AFTER consolidation phase

### Task 2: Graph walk module
**File:** NEW `src/core/graph-walk.ts`

Export `graphWalkFromSeeds(db, seedIds: number[], options?)`:
1. Takes seed artifact IDs (from initial RRF results)
2. Runs recursive CTE with depth limit 2:
   ```sql
   WITH RECURSIVE graph_walk(id, depth, score) AS (
     SELECT id, 0, ? FROM seed_values
     UNION ALL
     SELECT al.target_id, gw.depth + 1,
            gw.score * al.strength * 0.5
     FROM graph_walk gw
     JOIN artifact_links al ON al.source_id = gw.id
     WHERE gw.depth < 2
       AND al.invalid_at_epoch IS NULL
       AND gw.score * al.strength * 0.5 > 0.05
   )
   SELECT id, MAX(score) as walk_score FROM graph_walk WHERE id NOT IN (seed_ids) GROUP BY id ORDER BY walk_score DESC LIMIT ?
   ```
3. Return walked artifacts with scores
4. Link-type dampening: `caused_by` edges get 2× strength, `supports` get 1.5×, `contradicts` get 0 (exclude contradicted)

### Task 3: Integrate graph walk as 4th RRF channel
**File:** `src/core/hybrid-retrieval.ts`

In `hybridSearchAsync()`, after the existing 3 channels produce candidates:
1. Extract top-K artifact IDs from current results
2. Call `graphWalkFromSeeds(db, topKIds, { limit: 10 })`
3. Add walked artifacts as 4th channel in RRF fusion
4. RRF weight for graph channel: same as other channels (1/(60 + rank))
5. Wrap in try/catch — graph walk failure falls back to 3-channel RRF
