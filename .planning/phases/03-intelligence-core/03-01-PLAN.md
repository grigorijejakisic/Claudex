**src/intelligence/semantic-dedup.ts** — Pure functions, no DB dependency. Non-throwing pattern.

`normalizeForDedup(text: string): string` — Dedup-specific normalization per Architecture 6.3:
- `text.toLowerCase().replace(/[^\w\s]/g, '').replace(/\s+/g, ' ').trim()`
- Strips all punctuation (unlike text-utils normalize which preserves it)
- Returns empty string on falsy input

`porterStem(word: string): string` — Minimal Porter stemmer (~50 lines):
- Step 1a: sses→ss, ies→i, ss→ss, s→(remove)
- Step 1b: eed→ee (if stem has vowel+consonant), ed→(remove if stem has vowel), ing→(remove if stem has vowel), then cleanup: at→ate, bl→ble, iz→ize, double consonant→single (except ll/ss/zz)
- Step 2: ational→ate, tional→tion, enci→ence, anci→ance, izer→ize, abli→able, alli→al, entli→ent, eli→e, ousli→ous, ization→ize, ation→ate, ator→ate, alism→al, iveness→ive, fulness→ful, ousness→ous, aliti→al, iviti→ive, biliti→ble
- Step 3: icate→ic, ative→(remove), alize→al, iciti→ic, ical→ic, ful→(remove), ness→(remove)
- Step 5: Remove trailing e if stem measure > 1, or measure == 1 and stem doesn't end with CVC. Remove trailing ll if measure > 1.
- Non-throwing (return input word on error)

Stop word set (const, defined once):
```
the, a, an, is, are, was, were, be, been, being, have, has, had, do, does, did, will, would, could, should, may, might, shall, can, to, of, in, for, on, with, at, by, from, it, this, that, these, those, i, we, you, he, she, they
```

`extractKeywords(text: string): string[]` — Extract stemmed keywords:
1. `normalizeForDedup(text)` to strip punctuation
2. Split on whitespace
3. Filter out stop words
4. Apply `porterStem` to each remaining word
5. Return unique stemmed keywords (deduplicated)

`keywordJaccard(a: string, b: string): number` — Jaccard similarity on stemmed keyword sets:
1. `extractKeywords(a)` and `extractKeywords(b)` → Set A and Set B
2. intersection = A ∩ B, union = A ∪ B
3. Return intersection.size / union.size (0 if union is empty)

`isDuplicate(candidate: string, existing: string): boolean` — Returns true if any tier matches:
- Tier 1: `normalizeForDedup(candidate) === normalizeForDedup(existing)`
- Tier 2: `keywordJaccard(candidate, existing) >= 0.5`
- Tier 3: normalized candidate contains normalized existing, or vice versa
- Short-circuit: check tiers in order, return true on first match

`findDuplicate<T extends { content: string }>(candidate: string, existingItems: T[]): T | null` — Find matching existing entry:
- Iterate existingItems, call `isDuplicate(candidate, item.content)` for each
- Return first match, or null if none
- Used by learnings promoter to find existing learning for promotion

**src/tests/intelligence/semantic-dedup.test.ts** — Tests:

normalizeForDedup:
1. `strips punctuation and lowercases` — "We should use SQLite!" → "we should use sqlite"
2. `collapses whitespace` — "use   SQLite   for   storage" → "use sqlite for storage"
3. `returns empty string for falsy input`

porterStem:
4. `stems -ing words` — "running" → "run"
5. `stems -ed words` — "configured" → "configur"
6. `stems -tion words` — "ational" suffix handling (e.g., "relational" → "relat")
7. `stems -ies words` — "ponies" → "poni"
8. `returns short words unchanged` — "go" → "go"
9. `is non-throwing on empty input`

extractKeywords:
10. `removes stop words` — "use SQLite for the storage" → ["use", stemmed("sqlite"), stemmed("storag")]
11. `returns unique keywords` — "use use use" → ["use"]
12. `returns empty array for empty input`

keywordJaccard:
13. `returns 1.0 for identical text` — same keywords
14. `returns 0.0 for completely different text`
15. `returns ~0.5 for partial overlap` — texts sharing half their keywords
16. `returns 0 for empty inputs`

isDuplicate — Tier 1 (exact):
17. `matches case/punctuation variants` — "Use SQLite!" vs "use sqlite" → true
18. `rejects clearly different text` — "Use SQLite" vs "Use PostgreSQL" → false

isDuplicate — Tier 2 (Jaccard):
19. `matches semantic near-duplicates` — "Use SQLite for storage" vs "SQLite should be the storage layer" → true (>= 0.5)
20. `rejects low-overlap texts` — "Implement OAuth flow" vs "Fix database migration" → false

isDuplicate — Tier 3 (substring):
21. `matches when one contains the other` — "Use SQLite" vs "Use SQLite for the observation store" → true
22. `rejects non-contained different texts`

findDuplicate:
23. `returns matching existing item` — candidate matches item in list
24. `returns null when no match`
25. `returns first match when multiple exist`

Edge cases:
26. `isDuplicate is non-throwing (returns false on error)`
27. `findDuplicate handles empty list`
