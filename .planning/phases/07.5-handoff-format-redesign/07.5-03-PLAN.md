<task id="07.5-03-02">
  <subject>Author handoff-pickup-active probe</subject>
  <description>
Create `src/benchmark/vesna/probes/handoff-pickup-active.json`. Behavioral contract:

**Setup:**
- Project state: a working repo with `.planning/STATE.md` showing `Current Phase: <N>` and `context/handoffs/ACTIVE.md` in new-format with matching `phase: <N>` and a `summary: Resume <specific-action>` field.

**Question (user-facing prompt fed to a fresh session):**
> "Pick up where the handoff says."

**Pass criteria:**
- The fresh session's first action is one of:
  1. Reading `context/handoffs/ACTIVE.md` (soft-allowed — handoff-referenced),
  2. Producing a response that names the specific next-action from the handoff.

**Fail criteria (escapees):**
- The first action is `Glob`, `Grep`, `ls`, or `git status` of files NOT mentioned in the handoff,
- The session reports "I need more context" without reading ACTIVE.md,
- The response talks about a topic from prior conversation history rather than the handoff's `**What's next:**`.

Probe file shape (mirror existing Phase 6.5 probes — adapt as needed):

```json
{
  "name": "handoff-pickup-active",
  "category": "handoff-pickup",
  "description": "Fresh session picks up active handoff's next-action without exploratory tool use.",
  "tags": ["handoff", "SC4", "phase-7.5"],
  "setup": {
    "STATE.md_phase": "5",
    "ACTIVE.md": {
      "status": "active",
      "phase": "5",
      "summary": "Continue tier-deletion plan 03 wave 4",
      "topic": "phase-5-tier-deletion",
      "body_what_next": "Run plan 03 wave 4 — Tier A deletion of `Flow + Reference Layer + Materialization` sections."
    }
  },
  "user_prompt": "Pick up where the handoff says.",
  "assert_first_action": {
    "allowed_reads": ["context/handoffs/ACTIVE.md"],
    "must_match_response": "Tier A deletion|plan 03 wave 4",
    "forbid_tools": ["Glob", "Grep", "Bash:ls", "Bash:git status", "Bash:find"]
  }
}
```

If the harness JSON shape differs (e.g. uses `expected:` instead of `assert_first_action:`), adapt — the harness format wins.
  </description>
