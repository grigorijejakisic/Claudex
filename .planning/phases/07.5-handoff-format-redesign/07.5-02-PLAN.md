<task id="07.5-02-01">
  <subject>Write `scripts/migrate-handoff.ts` — re-runnable migration tool</subject>
  <description>
Create `scripts/migrate-handoff.ts` callable as `bun run scripts/migrate-handoff.ts <project-root>`. Behavior:

1. Read `<project-root>/context/handoffs/ACTIVE.md`. If missing: print "no active handoff to migrate" and exit 0.
2. Parse with `parseHandoffHeader` from `src/angel/handoff-writer.ts`.
3. **If parse succeeds AND body already starts with `**What we found:**`**: print "already in new format" and exit 0 (idempotent no-op).
4. **If parse succeeds but body is in transitional shape** (sections like `## What we found`, `## What's next — literal`, etc.): use a section-extractor that maps the actual section headers found in the current claudex-v3 ACTIVE.md (see fixture below) into the four bold-label fields. The extractor:
   - Map `## Where we are right now` + `## What we found (...)` → `**What we found:**` (concat with blank-line separator).
   - Map `## What we decided (...)` → `**What we decided:**`.
   - Map `## What's next — literal` + `## How to pick up tomorrow` → `**What's next:**` (concat).
   - Build `**Where to look:**` from any artifact references the body contains; if none, write `Files referenced inline above.`.
   - Title becomes `# <YYYY-MM-DD> — <topic>` where date and topic are derived from the existing first body line if it has the `# YYYY-MM-DD —` shape; else date is from `created_at_epoch_ms` (or today) and topic is `phase {N} handoff`.
5. **If parse fails (no YAML header at all)**: it's the legacy 372-line schema. Distill `## Commander's Intent` into `**What we found:**` + `**What we decided:**` (split heuristically on first sentence boundary), `## What's Left To Do` into `**What's next:**`, and any `## SBAR` artifacts list into `**Where to look:**`. If a heuristic can't distill, write the whole legacy body as `**What we found:**` and leave the other three sections as `(see archived original)`. **Do not silently drop content** — the archive copy preserves verbatim regardless.
6. **Always**: copy the original (pre-migration) ACTIVE.md verbatim to `<project-root>/context/handoffs/archive/<YYYY-MM-DD>-<topic-slug>.md` BEFORE writing the migrated file. If the archive target already exists, append `-N` until unique.
7. Build a `HandoffInput` and call `writeHandoff` to (re-)write ACTIVE.md atomically. Always set:
   - `status` = parsed `status` if present, else `'active'`
   - `phase` = parsed `phase` (string)
   - `summary` = parsed `summary` if present, else derive from `**What's next:**` first line (truncate ≤140 chars, strip Markdown), else `Resume phase {phase} handoff`.
   - `topic` = parsed `topic` if present, else slugified date+phase (`2026-04-27-phase-4-1`).
   - `created_at_epoch_ms` = parsed if present, else `Date.now()`.
8. Print a one-line summary: `migrated <path> → archive <archive-path>`.

Idempotency contract: running the script twice on the same project must produce the same result on the second run as the first (archive made once, ACTIVE.md unchanged on second run).

Add a CLI guard: if no `<project-root>` argument and `process.cwd()` is a git repo containing `context/handoffs/ACTIVE.md`, default to `process.cwd()`. Otherwise exit with usage message.
  </description>
  <verification>

3. **Rewrite `renderHandoff` (lines 411-434)** to:

```typescript
export function renderHandoff(project: string): string {
  const header = '## Handoff\n\n';
  try {
    const projectPath = resolveProjectPath(project);
    if (!projectPath) return header + 'No active handoff.\n';

    const handoffPath = path.join(projectPath, 'context', 'handoffs', 'ACTIVE.md');
    if (!fs.existsSync(handoffPath)) return header + 'No active handoff.\n';

    let raw: string;
    try {
      raw = fs.readFileSync(handoffPath, 'utf8');
    } catch {
      return header + 'No active handoff.\n';
    }

    const parsed = parseHandoffHeader(raw);
    if (!parsed) return header + 'No active handoff.\n';

    const phase = parsed.phase;
    const topic = parsed.topic ?? parsed.summary ?? 'unspecified';
    switch (parsed.status) {
      case 'active':
        return header + `Active handoff at phase ${phase}: ${topic}.\nSee: context/handoffs/ACTIVE.md\n`;
      case 'paused':
        return header + `Handoff paused at phase ${phase}.\nSee: context/handoffs/ACTIVE.md\n`;
      case 'archived':
      default:
        return header + 'No active handoff.\n';
    }
  } catch {
    return header + 'No active handoff.\n';
  }
}
```

4. **Update the section budget order in the trim helper** (lines 633-671): `sections.handoff` is now near-fixed-size (≤120 chars typically), so its priority in the trim cascade can stay where it is. Verify the existing `trimTail(sections.handoff)` regex `/^- /m` still matches; if `## Handoff` no longer emits any `- ` bullet lines (it doesn't — output is plain prose), the `while (...) { trimTail }` loop simply won't fire on this section. That's correct behavior — the section is small enough not to need trimming. **No code change required to the trim helper, but document this in the JSDoc** above `trimTail`.

5. **Update the section header JSDoc at the top of the file** (line 13): `## Handoff (one-line status summary + pointer to ACTIVE.md)`.
