## What shipped

- **`scripts/migrate-handoff.ts`** (~190 lines) — re-runnable migration tool. Three branches: (a) already-new-format → no-op; (b) transitional (YAML + `## Where we are…` body) → section-map extractor maps existing headers into the four bold-label fields; (c) legacy 372-line schema (no YAML) → distill `## Commander's Intent` + `## What's Left To Do` heuristically. Always archives original verbatim BEFORE writing.
- **`src/angel/memory-md-writer.ts`** — `renderHandoff` rewritten to call `parseHandoffHeader`. Three status branches: `active` → `Active handoff at phase N: topic.\nSee: …`; `paused` → `Handoff paused at phase N.\nSee: …`; `archived` (or any falsy/malformed parse) → `No active handoff.` Old `distillHandoffBody` function (~48 LOC) and `MAX_HANDOFF_LINES` constant deleted. JSDoc updated.
- **`src/tests/angel/memory-md-writer.test.ts`** — old 4 `renderHandoff` tests (line-count distillation, mid-line truncation guards, etc.) replaced with 7 new tests covering active/paused/archived/missing/malformed/legacy-rejected/never-leak-body contracts.
- **`context/handoffs/ACTIVE.md`** — migrated. Now ~10-line YAML header + 4 bold-label sections. Summary derived from `**What's next:**` first line, contains `Phase 4.1` per plan requirement.
- **`context/handoffs/archive/2026-04-27-phase-4-1-design-discussion.md`** — verbatim pre-migration ACTIVE.md (372-line transitional shape).
