<objective>
Hook infrastructure and 6 CC hook entry points: the adapter layer that wires all core subsystems into Claude Code's lifecycle hook system.

Purpose: Each CC hook is an ephemeral Node.js process that reads stdin JSON, opens SQLite, calls the appropriate core pipeline functions, writes stdout JSON, and exits. The infrastructure module provides shared utilities (stdin/stdout protocol, DB bootstrap, latency-tracked error wrapper). Without this, Claudex v3 has no runtime — all the core modules have no entry points.

Output: `infrastructure.ts` (shared hook utilities), 6 hook entry point files (`session-start.ts`, `user-prompt-submit.ts`, `post-tool-use.ts`, `stop.ts`, `pre-compact.ts`, `session-end.ts`), and their tests.

**src/adapters/cc-hooks/infrastructure.ts** — Shared infrastructure for all CC hook entry points.

Imports: `openDatabase`, `closeDatabase` from `../../core/storage.js`; `loadConfig` from `../../shared/config.js`; `detectProjectScope` from `../../shared/scope-detector.js`; `getDbPath` from `../../shared/paths.js`; `emitTelemetry` from `../../observability/telemetry.js`; `CC_CAPABILITIES` from `../../shared/constants.js`; `Database` type from `better-sqlite3`; `ClaudexConfig` type from `../../shared/config.js`.

Types:
```typescript
/** Parsed CC hook stdin payload. */
export interface HookInput {
  hook_event_name: string;
  session_id: string;
  cwd: string;
  // SessionStart has no extra fields
  // UserPromptSubmit: user_prompt (string)
  // PostToolUse: tool_name (string), tool_input (object), tool_output (object)
  // Stop: stop_hook_active (boolean), transcript_path (string)
  // PreCompact: (no extra fields)
  // SessionEnd: (no extra fields)
  [key: string]: unknown;
}

/** Bootstrap result: DB + config + project scope. */
export interface BootstrapResult {
  db: Database;
  config: ClaudexConfig;
  project: string;
  scope: string | null;
}

/** Hook handler function signature. */
export type HookHandler = (input: HookInput, ctx: BootstrapResult) => Promise<Record<string, unknown>>;
```

Functions:

`readStdin(): Promise<HookInput>`:
- Reads all data from `process.stdin` (collect chunks into buffer, resolve on 'end')
- `JSON.parse` the concatenated string
- If parse fails or input is not an object, return `{ hook_event_name: '', session_id: '', cwd: '' }` (safe default)
- Non-throwing wrapper: catch any error, return safe default

`writeStdout(output: Record<string, unknown>): void`:
- `process.stdout.write(JSON.stringify(output) + '\n')`
- Non-throwing: wrap in try/catch, swallow errors

`bootstrapHook(input: HookInput): BootstrapResult`:
- Opens DB via `openDatabase(getDbPath())`
- Loads config via `loadConfig()`
- Detects project scope via `detectProjectScope(input.cwd)` — returns project ID or uses cwd as fallback project name
- The `scope` is the raw result from `detectProjectScope` (may be null)
- If project is null, derive a simple project name from `input.cwd` (last path component or full path)
- Returns `{ db, config, project, scope }`
- Non-throwing: if DB open fails, throw (let wrapHook catch it)

`detectAdapter(): 'cc-hooks' | 'openclaw-bridge'`:
- Check `typeof globalThis !== 'undefined' && globalThis[Symbol.for('claudex-bridge')]`
- If exists: return `'openclaw-bridge'`
- Otherwise: return `'cc-hooks'`
- Non-throwing

`getTranscriptPath(input: HookInput): string | undefined`:
- CC provides transcript path in the input payload
- Check `input.transcript_path` as string — return it if present
- Also check `input.transcriptPath` (camelCase variant)
- Return undefined if not present

`wrapHook(hookName: string, handler: HookHandler): () => Promise<void>`:
- Returns an async function that:
  1. `const startMs = Date.now()`
  2. Calls `readStdin()` to get input
  3. Calls `bootstrapHook(input)` to get ctx
  4. Calls `handler(input, ctx)` to get output
  5. Emits telemetry: `emitTelemetry(ctx.db, input.session_id, 'hook_invocation', { hook: hookName, event_kind: hookToEventKind(hookName), latency_ms: elapsed }, elapsed)`
  6. Calls `writeStdout(output)`
  7. Calls `closeDatabase(ctx.db)` in `finally`
  8. On any error: `writeStdout({})`, log nothing (silent fail per spec), still close DB
- The hookToEventKind mapping: `{ SessionStart: 'session_init', UserPromptSubmit: 'before_prompt', PostToolUse: 'after_tool', Stop: 'after_turn', PreCompact: 'before_compact', SessionEnd: 'session_end' }`

**src/adapters/cc-hooks/user-prompt-submit.ts** — UserPromptSubmit -> before_prompt

Imports: `wrapHook`, `getTranscriptPath` from `./infrastructure.js`; `getCheckpointTracking`, `clearPostCompactPending` from `../../core/checkpoint-tracking.js`; `getTokenGauge` from `../../gauge/token-gauge.js`; `CC_CAPABILITIES` from `../../shared/constants.js`; `assembleRegularPrompt` from `../../assembly/assembler.js`; `TopicShiftDetector` from `../../intelligence/topic-shift.js`; `EmbeddingProvider` from `../../embeddings/embedding-provider.js`; `getIdentityDir` from `../../shared/paths.js`.

Handler logic:
1. Extract user prompt: `const prompt = (input.user_prompt as string) || ''`
2. Check post-compaction: `const tracking = getCheckpointTracking(ctx.db, input.session_id)`; `const isPostCompaction = tracking?.post_compact_pending === 1`
3. Get token gauge: `const gauge = getTokenGauge({ capabilities: CC_CAPABILITIES, transcriptPath: getTranscriptPath(input), model: (input.model as string) ?? undefined })`
4. Detect topic shift (only if not post-compaction and prompt is non-empty):
   - Try to create `EmbeddingProvider` and check availability: `const embedProvider = new EmbeddingProvider({ baseUrl: ctx.config.embeddings.ollama_base_url, model: ctx.config.embeddings.model }); const available = await embedProvider.isAvailable()`
   - Create detector: `const detector = new TopicShiftDetector(available ? embedProvider : null)`
   - Detect: `const topicShift = await detector.detectTopicShift({ prompt, db: ctx.db, sessionId: input.session_id, config: { topicShiftThreshold: ctx.config.embeddings.topic_shift_threshold, topicShiftWindow: ctx.config.embeddings.topic_shift_window } })`
   - If not detecting topic shift (post-compaction or empty prompt): `topicShift = null`
5. Assemble: `const payload = assembleRegularPrompt({ isPostCompaction, prompt, gauge, topicShift, db: ctx.db, project: ctx.project, projectDir: input.cwd, config: ctx.config, identityDir: getIdentityDir() })`
6. If `isPostCompaction`: `clearPostCompactPending(ctx.db, input.session_id)`
7. If `payload.content`: return `{ systemMessage: payload.content }`
8. Otherwise: return `{}`
