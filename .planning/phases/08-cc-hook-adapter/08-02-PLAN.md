**src/cli/setup.ts** — `claudex setup` entry point.

Imports: `openDatabase`, `closeDatabase` from `../core/storage.js`; `initializeSchema`, `migrateFromV2` from `../core/migrations.js`; `getDbPath`, `getClaudexHome`, `getConfigPath` from `../shared/paths.js`; `ensureDir`, `readJsonFile`, `writeJsonFile` from `../shared/fs-helpers.js`; `DEFAULT_CONFIG`, `SCHEMA_VERSION` from `../shared/constants.js`; `fs`, `path`, `os`, `readline`.

Constants:
```typescript
/** Hook file names matching build.ts output in dist/. */
const HOOK_FILES: Record<string, string> = {
  SessionStart: 'session-start.js',
  UserPromptSubmit: 'user-prompt-submit.js',
  PostToolUse: 'post-tool-use.js',
  Stop: 'stop.js',
  PreCompact: 'pre-compact.js',
  SessionEnd: 'session-end.js',
};
```

Exported functions (for testability):

`getHookPaths(installDir: string): Record<string, string>`:
- For each entry in HOOK_FILES, resolve absolute path: `path.resolve(installDir, 'dist', filename)`
- Return map: `{ SessionStart: '/abs/path/dist/session-start.js', ... }`

`getSettingsJsonPath(): string`:
- Returns `path.join(os.homedir(), '.claude', 'settings.json')`

`patchSettingsJson(settingsPath: string, hookPaths: Record<string, string>): { patched: boolean; created: boolean }`:
- Read existing settings.json via `readJsonFile(settingsPath)` — may return null if doesn't exist
- If null: create new object `{ hooks: {} }`
- Ensure `settings.hooks` exists as an object
- For each hook in hookPaths:
  - The CC hooks settings.json format is:
    ```json
    {
      "hooks": {
        "SessionStart": [
          { "matcher": "", "hooks": [{ "type": "command", "command": "node /path/to/dist/session-start.js" }] }
        ]
      }
    }
    ```
  - Build the hook entry: `{ matcher: '', hooks: [{ type: 'command', command: 'node ' + hookPaths[hookName] }] }`
  - Check if hook array already exists for this event name
  - If exists: find any entry whose hooks contain a command with 'claudex' or 'CLAUDEXv3' in the path, and replace it. If no Claudex entry found, append new entry.
  - If not exists: create array with new entry
- Write merged settings back via `writeJsonFile(settingsPath, settings)`
- Return `{ patched: true, created: !existed }`

`detectV2Database(dbPath: string): { detected: boolean; observationCount: number; sessionCount: number; pressureCount: number } | null`:
- If file doesn't exist at dbPath: return null
- Open database at dbPath (read-only if possible, or regular open)
- Check if schema_versions table exists: `SELECT name FROM sqlite_master WHERE type='table' AND name='schema_versions'`
- If no schema_versions table: return null (not a Claudex DB)
- Check version: `SELECT MAX(version) as version FROM schema_versions`
- If version >= SCHEMA_VERSION (300): return null (already v3)
- Count observations: `SELECT COUNT(*) as count FROM observations` (catch if table doesn't exist)
- Count sessions: `SELECT COUNT(*) as count FROM sessions` (catch)
- Count pressure_scores: `SELECT COUNT(*) as count FROM pressure_scores` (catch)
- Close DB
- Return `{ detected: true, observationCount, sessionCount, pressureCount }`
- Non-throwing: return null on any error

`async function main()`:
1. Print banner: `console.log('Claudex v3 Setup')`; `console.log('================\n')`
2. Create directory structure:
   - `ensureDir(getClaudexHome())` — `~/.claudex/`
   - `ensureDir(path.join(getClaudexHome(), 'db'))` — `~/.claudex/db/`
   - `ensureDir(path.join(getClaudexHome(), 'identity'))` — `~/.claudex/identity/`
   - Print: `console.log('[OK] Directory structure created: ~/.claudex/')`
3. Initialize database:
   - `const dbPath = getDbPath()`
   - `const db = openDatabase(dbPath)`
   - `initializeSchema(db)`
   - `closeDatabase(db)`
   - Print: `console.log('[OK] Database initialized: ' + dbPath)`
4. Write default config (only if not exists):
   - `const configPath = getConfigPath()`
   - If file doesn't exist: `writeJsonFile(configPath, DEFAULT_CONFIG)`; print `[OK] Config written: configPath`
   - If file exists: print `[OK] Config already exists: configPath (preserved)`
5. Patch settings.json:
   - Determine install directory: `const installDir = path.resolve(__dirname, '..')` or use `process.cwd()` — the install dir is where the `dist/` folder lives. Use `path.resolve(path.dirname(process.argv[1] || ''), '..')` as heuristic, with fallback to `process.cwd()`.
   - Actually: since this runs as `node dist/setup.js`, the install dir is `path.resolve(path.dirname(process.argv[1] || __filename), '..')`. But simpler: resolve relative to the actual CLAUDEXv3 project root. Use `path.resolve(path.dirname(new URL(import.meta?.url ?? 'file://' + __filename).pathname), '..')` — OR just compute based on `__dirname` since build produces CJS.
   - Simplest approach: the setup.ts can detect its own location via `__dirname` at runtime, and resolve dist/ relative to it. Since esbuild bundles to `dist/setup.js`, `__dirname` in the bundle is the `dist/` directory, so installDir = `path.resolve(__dirname, '..')`.
   - But better: expose it as a parameter for testability. `getHookPaths(installDir)` takes the install dir.
   - In main(): `const installDir = path.resolve(__dirname, '..')`
   - `const hookPaths = getHookPaths(installDir)`
   - `const settingsPath = getSettingsJsonPath()`
   - `const result = patchSettingsJson(settingsPath, hookPaths)`
   - Print: `[OK] Hook paths registered in: settingsPath` (+ `(created)` if result.created)
6. v2 migration check:
   - `const v2Info = detectV2Database(dbPath)` — check if the DB we just initialized was actually a v2 DB (would have version < 300 before we ran initializeSchema). BUT: we already ran initializeSchema which sets version 300. So the v2 check needs to happen BEFORE initializeSchema.
   - **Revised order**: Check for v2 BEFORE initializing schema:
     a. Open DB, check if schema_versions exists and max(version) < 300
     b. If v2 detected: print stats, ask user (if interactive) or skip (if non-interactive)
     c. If migration accepted: backup first (`fs.copyFileSync(dbPath, dbPath + '.v2-backup')`), then run `migrateFromV2(db)`
     d. Then run `initializeSchema(db)` (which is safe with CREATE IF NOT EXISTS)
     e. If no v2: just run `initializeSchema(db)` normally
   - For non-interactive detection: check if `process.stdin.isTTY` is true
   - If interactive and v2 detected: use `readline` to prompt `Migrate v2 data? [y/N]`
   - Print migration result if performed: `[OK] v2 data migrated (backup: dbPath.v2-backup)`
7. Print final summary:
   ```
   Setup complete! Claudex v3 is ready.
   - Database: ~/.claudex/db/claudex.db
   - Config: ~/.claudex/config.json
   - Hooks: 6 registered in ~/.claude/settings.json
   ```
8. `process.exit(0)` on success

Error handling: wrap entire main in try/catch. On error: `console.error('[ERROR] Setup failed:', error.message)`; `process.exit(1)`.

Run main at module level: `main().catch(() => process.exit(1))`.
