export const WILSON_Z_95 = 1.959964 as const;

export interface CI {
  point: number;   // point estimate
  lower: number;   // lower bound at z (default 95%)
  upper: number;   // upper bound at z (default 95%)
  n: number;       // sample size used
}

/** Wilson score interval for a binomial proportion. successes <= n; 0 <= p <= 1. */
export function wilsonCI(successes: number, n: number, z?: number): CI;

/**
 * Wilson-style CI on the DELTA between two independent proportions p2 - p1.
 * Implementation: Newcombe's method 10 (hybrid score) — the standard reference
 * for delta-of-proportions when sample sizes can be small (n ~ 40-60 in our case).
 * Returns CI of the difference (p2 - p1).
 *
 * IMPORTANT — paired-vs-independent caveat (per checker-02-04 verification):
 * Newcombe method 10 is the INDEPENDENT-proportions form. Our harness evaluates
 * Variant A and Variant C on the SAME query set, so the dichotomized-success
 * vectors are PAIRED (positively correlated across variants). Applying the
 * independent-proportions form to paired data produces conservatively WIDER
 * intervals — i.e., it makes green-light HARDER, not easier. This biases AGAINST
 * false green-light, which is the empirically-honest direction for an empirical
 * phase. Tango's paired score (Stat Med 1998, the paired-score sibling of method
 * 10) would be tighter but adds dependency on within-query correlation modeling;
 * the conservative choice here is deliberate. A future revision could switch to
 * the paired score for tighter CIs once the multi-handle thesis has cleared the
 * conservative bar.
 */
export function wilsonDeltaCI(s1: number, n1: number, s2: number, n2: number, z?: number): CI;
```

**Implementation notes:**
- Use the standard closed-form Wilson formula: center = (p + z²/(2n)) / (1 + z²/n); halfWidth = z * sqrt(p(1-p)/n + z²/(4n²)) / (1 + z²/n).
- Handle n=0 by returning `{ point: 0, lower: 0, upper: 0, n: 0 }` — never NaN. Document this in a JSDoc.
- For Newcombe's method: compute Wilson CI on each proportion separately to get (l1,u1) and (l2,u2); the delta CI is (p2-p1 - sqrt((p1-l1)² + (u2-p2)²), p2-p1 + sqrt((u1-p1)² + (p2-l2)²)). This is the published formula — implement faithfully.
- Pure function: no clocks, no random, no I/O.

**Avoid:**
- Approximating with the normal/Wald interval — CONTEXT explicitly mandates Wilson, and Wald is bad at small n.
- Returning negative-lower-bound values clamped to 0 for the proportion CI — the Wilson formula already keeps proportion bounds in [0,1] without clamping; for the DELTA CI the lower bound CAN be negative (that's the point), so do NOT clamp the delta version.

export interface DensitySignal {
  noise_floor: number;             // 95th-percentile similarity from 1000 random pairs
  noise_sigma: number;             // sample stddev of the 1000 random pairs
  cluster_threshold: number;       // noise_floor + 2 * noise_sigma
  cluster_count: { weak_K2: number; strong_K5: number };
  intra_project_share: number;     // 0..1 — fraction of high-similarity pairs (sim > cluster_threshold) that are same-project
  density_meaningful: boolean;     // intra_project_share >= 0.30 (CONTEXT item 4)
  random_pair_sample_size: number; // = 1000
}

export function computeDensitySignal(events: IndexedEvent[], opts?: { sample?: number; seed?: number }): DensitySignal;
```

**Implementation:**
1. Compute pairwise Jaccard similarity over shingle sets for any (a, b): `J = |A ∩ B| / |A ∪ B|` (where A and B are the shingle Sets). Pure CPU; no DB.
2. **Noise floor**: with seeded PRNG (default seed=4242), draw `opts.sample ?? 1000` random (i, j) pairs (i ≠ j) from `events`. Compute Jaccard for each. `noise_floor` = 95th percentile (linear interpolation), `noise_sigma` = sample stddev.
3. **Cluster classification**: enumerate all (a, b) with a.id < b.id. For each pair where Jaccard > `cluster_threshold = noise_floor + 2 * noise_sigma`, it's a "high-similarity edge." Build connected components by union-find. K = component size.
   - `cluster_count.weak_K2` = components with size ≥ 2 AND size < 5.
