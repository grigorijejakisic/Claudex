Create `src/core/error-fingerprint.ts` exporting:

```typescript
export const FINGERPRINT_ALGORITHM_VERSION = 1 as const;
export const SHINGLE_WIDTH = 5 as const;

export interface ErrorFingerprint {
  shingles: string[];           // sorted unique 16-hex-char shingle hashes
  outer_exception: string | null; // e.g. 'TypeError', 'sqlite3.OperationalError'
  frame_count: number;          // count of detected stack frames
  shingle_width: number;        // = SHINGLE_WIDTH
  algorithm_version: number;    // = FINGERPRINT_ALGORITHM_VERSION
}

export function looksLikeStackTrace(content: string): boolean;
export function computeErrorFingerprint(content: string): ErrorFingerprint | null;
```

**Implementation requirements:**

1. **`looksLikeStackTrace(content: string): boolean`** — heuristic regex check, conservative per CONTEXT discretion:
   - Match if ANY of:
     - Two or more consecutive lines matching `^\s+at\s+\S+` (Node.js stack)
     - Two or more lines matching `^\s+File ".+", line \d+` (Python traceback)
     - One line containing `Traceback (most recent call last):`
     - Two or more lines containing both a colon-separated path-like token (`\S+:\d+(:\d+)?`) AND a function-name-like token
     - Outer exception detected via `^(?:[\w.]+(?:Error|Exception|Failed|Failure)):\s` regex (one match enough)
   - Return false if none. The decision must be deterministic on any string input (no exceptions thrown).

2. **`computeErrorFingerprint(content: string): ErrorFingerprint | null`**:
   - If `looksLikeStackTrace(content)` returns false → return null.
   - Otherwise:
     - **Outer exception**: extract via the same regex used in detection; if no match, set null.
     - **Frame extraction**: split on newlines; for each line, attempt to extract `(file, line, func)` tuples by trying in order: Node.js (`at <func> (<file>:<line>:<col>)` or `at <file>:<line>:<col>`), Python (`File "<file>", line <line>, in <func>`), generic (`<file>:<line>` + adjacent function-like token). Frames missing func use empty string for func. Frames with no file:line are skipped. `frame_count` = number of successful extractions.
     - **Shingles**: token-shingle algorithm:
       - Tokenize content by whitespace (split on `/\s+/`), preserving order.
       - Build n-grams of width `SHINGLE_WIDTH` (5).
       - For each n-gram, join with single space and hash via Node's `crypto.createHash('sha256')`, take the first 16 hex chars.
       - Deduplicate (Set) and sort lexicographically for byte-stable output.
     - Return the fingerprint object.

**Determinism contract** (test in Task 3):
- `computeErrorFingerprint(s)` MUST be referentially transparent: no clocks, no random, no Date, no env reads.
- For any string s, `computeErrorFingerprint(s)` deep-equals `computeErrorFingerprint(s)` across processes.

**Avoid:**
- Calling out to Ollama, embedding services, or the reranker — fingerprinter is pure.
- Edit-distance computation here. CONTEXT discretion picks Jaccard-on-shingles for Plan 02-04's similarity; this module's output is the shingle set used by both the sidecar and the harness.
- Storing anything to DB from this module — pure compute only.
- Importing `better-sqlite3` — fingerprinter has no DB dependency.
