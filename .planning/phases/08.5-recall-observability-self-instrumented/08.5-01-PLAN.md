## Schema (locked in CONTEXT.md, restated for clarity)

```sql
CREATE TABLE IF NOT EXISTS retrieval_log (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  session_id TEXT NOT NULL,
  invoked_at_epoch_ms INTEGER NOT NULL,
  surface TEXT NOT NULL CHECK (surface IN (
    'claudex_search', 'claudex_recall', 'pointer_surface', 'mcp_other'
  )),
  query TEXT,
  top_k_results TEXT NOT NULL DEFAULT '[]'
    CHECK (json_valid(top_k_results)),
  used_in_output INTEGER NOT NULL DEFAULT 0
    CHECK (used_in_output IN (0, 1)),
  token_cost INTEGER NOT NULL DEFAULT 0
);

CREATE INDEX IF NOT EXISTS idx_retrieval_log_session
  ON retrieval_log(session_id, invoked_at_epoch_ms DESC);
```

`session_id` is TEXT to match other Claudex tables (often `mcp:<project>` or
a UUID); no FK to `sessions` since MCP retrievals can fire before a CC
session row is created.

`top_k_results` is TEXT-with-`json_valid` check — gives us schema-level
guard against bad inserts without committing to JSON1 search.

`used_in_output` defaults to 0 at insert; reconciler flips matches to 1.

  <subject>Create src/intelligence/retrieval-log.ts helper module</subject>
  <description>

```typescript
import type { Database } from 'better-sqlite3';
import { cachedPrepare } from '../core/stmt-cache.js';
import { countTokensCl100k } from '../shared/text-utils.js';

export type RetrievalSurface =
  | 'claudex_search'
  | 'claudex_recall'
  | 'pointer_surface'
  | 'mcp_other';

export interface RetrievalLogInput {
  sessionId: string;
  surface: RetrievalSurface;
  query: string | null;
  topKResults: Array<{ id: number | string; source: string; score: number }>;
  responseText: string;        // The text the agent receives — used for token_cost
  invokedAtEpochMs?: number;   // Defaults to Date.now()
}

export interface RetrievalLogRow {
  id: number;
  session_id: string;
  invoked_at_epoch_ms: number;
  surface: RetrievalSurface;
  query: string | null;
  top_k_results: string;        // JSON
  used_in_output: 0 | 1;
  token_cost: number;
}

/**
 * Insert a single retrieval event. Non-throwing — returns the inserted id
 * or 0 on failure (callers' retrieval responses must never break because
 * logging failed).
 */
export function recordRetrieval(
  db: Database,
  input: RetrievalLogInput,
): number {
  try {
    const tokenCost = countTokensCl100k(input.responseText);
    const ts = input.invokedAtEpochMs ?? Date.now();
    const json = JSON.stringify(input.topKResults);
    const result = cachedPrepare(db,
      `INSERT INTO retrieval_log
         (session_id, invoked_at_epoch_ms, surface, query, top_k_results, used_in_output, token_cost)
       VALUES (?, ?, ?, ?, ?, 0, ?)`
    ).run(input.sessionId, ts, input.surface, input.query, json, tokenCost);
    return Number(result.lastInsertRowid) || 0;
  } catch {
    return 0;
  }
}

/**
 * Return all retrieval rows for a session, ordered by invoked_at ascending
 * (chronological — what /claudex-why renders).
 */
export function listSessionRetrievals(
  db: Database,
  sessionId: string,
): RetrievalLogRow[] {
  return cachedPrepare(db,
    `SELECT id, session_id, invoked_at_epoch_ms, surface, query, top_k_results, used_in_output, token_cost
       FROM retrieval_log
      WHERE session_id = ?
      ORDER BY invoked_at_epoch_ms ASC`
  ).all(sessionId) as RetrievalLogRow[];
}

/**
 * Aggregate token cost + invocation counts for a session.
 * Used by /endsession summary and /claudex-why footer.
 */
export function aggregateSessionCost(
  db: Database,
  sessionId: string,
): {
  invocations: number;
  totalTokens: number;
  usedCount: number;
  hitRate: number;     // used / invocations, 0 if invocations = 0
  bySurface: Record<RetrievalSurface, { count: number; tokens: number }>;
} {
  const rows = listSessionRetrievals(db, sessionId);
  const totals = rows.reduce(
    (acc, r) => {
      acc.invocations++;
      acc.totalTokens += r.token_cost;
      if (r.used_in_output === 1) acc.usedCount++;
      const surf = r.surface as RetrievalSurface;
      const bucket = acc.bySurface[surf] ?? { count: 0, tokens: 0 };
      bucket.count++;
      bucket.tokens += r.token_cost;
      acc.bySurface[surf] = bucket;
      return acc;
    },
    {
      invocations: 0,
      totalTokens: 0,
      usedCount: 0,
      bySurface: {} as Record<RetrievalSurface, { count: number; tokens: number }>,
    },
  );
  const hitRate = totals.invocations > 0 ? totals.usedCount / totals.invocations : 0;
  return { ...totals, hitRate };
}

/**
 * Mark a set of retrieval_log rows as used_in_output=1.
 * Idempotent — only flips 0 → 1 (never 1 → 0).
 * Returns rows updated.
 */
export function markRetrievalUsed(
  db: Database,
  retrievalIds: number[],
): number {
  if (retrievalIds.length === 0) return 0;
  const placeholders = retrievalIds.map(() => '?').join(',');
  const result = cachedPrepare(db,
    `UPDATE retrieval_log
        SET used_in_output = 1
      WHERE id IN (${placeholders})
        AND used_in_output = 0`
  ).run(...retrievalIds);
  return Number(result.changes);
}

/**
 * Run the used_in_output heuristic for a session.
 *
 * For each retrieval_log row in the session:
 *   - Take top_k_results' summary/content (resolve from artifacts table).
 *   - Tokenize into distinctive tokens (length ≥ 6, lowercase, no stopwords).
 *   - Look at transcript_chunk rows where session_id matches AND
 *     timestamp_epoch >= retrieval.invoked_at_epoch_ms AND ordered first 5
 *     assistant chunks within that window.
 *   - If ≥ 2 distinctive tokens overlap → mark used_in_output = 1.
 *
 * Returns rows updated. Non-throwing (logs nothing on internal failure;
 * caller treats 0 as "nothing to update or could not run").
 */
export function reconcileUsedInOutput(
  db: Database,
  sessionId: string,
): { rowsUpdated: number };
```

Implementation notes for `reconcileUsedInOutput`:

- Stopword set: top-50 English stopwords (a, an, the, and, or, of, to,
  in, is, was, this, that, with, for, on, as, by, at, from, it, its,
  but, not, no, are, were, has, have, had, be, been, do, does, did, can,
  will, would, should, could, may, might, must, our, your, their, my,
  his, her, who, what, where).
- Distinctive token: `/[a-z][a-z0-9_-]{5,}/` (length ≥ 6 alphanumeric).
- Resolve `top_k_results[].id` against `artifacts.id` for `claudex_recall`
  and `claudex_search` artifact-source rows; for `journal_flow`,
  `conversation_turn`, `pointer_surface` sources, fall back to the
  `recall_text` / `summary` field if the source table has it. If
  resolution fails for a row, skip it (no false positive).
- Window: `transcript_chunk.timestamp_epoch >= retrieval.invoked_at_epoch_ms / 1000`
  (transcript_chunk uses seconds; retrieval_log uses ms — divide).
- Take first 5 assistant chunks within window:
  `SELECT content FROM transcript_chunk WHERE session_id=? AND chunk_type='assistant' AND timestamp_epoch >= ? ORDER BY timestamp_epoch ASC LIMIT 5`.
  If `chunk_type` column doesn't exist in this codebase, fall back to
  `WHERE session_id=? AND timestamp_epoch >= ? ORDER BY ... LIMIT 5` and
  filter content side that's not user-prefixed. Confirm column name via
  `grep -n "chunk_type" src/core/schema.ts` at task time.
- Overlap: intersect distinctive-token set from retrieval response with
  union-of-distinctive-tokens from the 5 assistant chunks. If
  `|intersection| >= 2`, mark.
- Wrap the whole pass in a single transaction.

Do not throw. If `transcript_chunk` is empty for the session (typical
during tests), return `{ rowsUpdated: 0 }`.
