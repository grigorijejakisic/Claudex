# Phase 8.5 — Summary

## What shipped

**4 deliverables, 6 plans, 4 waves, all closed.**

1. **Per-session retrieval log (OBS-01).** New V22 schema (`retrieval_log` +
   `session_flag`); helper module `src/intelligence/retrieval-log.ts`
   exposes `recordRetrieval`, `listSessionRetrievals`, `aggregateSessionCost`,
   `markRetrievalUsed`, `reconcileUsedInOutput`. The MCP server's
   `claudex_search` and `claudex_recall` handlers log every retrieval
   event with the cl100k_base token cost of the JSON the agent receives.

2. **Self-narration directive + /silent toggle (OBS-02).** Three locked
   advisory-voice templates (empty-surface / gold / ambiguous) appended to
   `CLAUDEX_INSTRUCTIONS` in `recall-server.ts`. Per-session `/silent`
   suppression is honored by the agent reading the `session_flag` row;
   `claudex_session` accepts new `narration_silent_on/off` actions.

3. **Visible token cost at /endsession (OBS-03).** New CLI
   `dist/cli/session-token-cost.cjs` reads `retrieval_log` + existing
   `telemetry(injection)` rows and prints the CONTEXT.md format block
   (`session-start / UPS turns / explicit retrieval / total`).
   Reconciles `used_in_output` before reading. Skill `Step 1e` added to
   `~/.claude/skills/endsession/skill.md`.

4. **/claudex-why slash command (OBS-04).** New CLI
   `dist/cli/why.cjs` renders chronological retrieval lines + aggregate
   footer per the locked format
   `[T+M:SS] surface(query) → N results, M used, K tokens`.
   New skill `~/.claude/skills/claudex-why/skill.md`.
