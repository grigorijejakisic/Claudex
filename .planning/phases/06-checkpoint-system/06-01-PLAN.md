**src/checkpoint/writer.ts** — DB-first checkpoint writer. Non-throwing public API.

Import `ulid` from the `ulid` package. Import `js-yaml` for YAML serialization. Import types from `./types.ts`.

`extractOpenItems(text: string): string[]` — Extract open items from assistant text:
- If text is empty/null, return []
- Regex patterns to match: `TODO:?\s+(.+)`, `FIXME:?\s+(.+)`, `HACK:?\s+(.+)`, case-insensitive
- Also match: `(?:remaining|still need|need to)\s+(.+)` (sentence fragments)
- Extract captured group, trim, deduplicate
- Return array of extracted strings
- Non-throwing (return [] on error)

`shouldTriggerCheckpoint(params: { trigger: CheckpointTrigger; tokenUsage?: TokenUsage; tracking?: CheckpointTrackingRow; debounceSeconds?: number }): boolean` — Trigger logic:
- If trigger is `'compaction'`: return true (always, bypass debounce)
- If trigger is `'session_end'`: return true (always)
- If trigger is `'threshold'`:
  - If no tokenUsage: return false (can't check thresholds without usage data)
  - Determine thresholds based on window_size: use THRESHOLDS_200K if < WINDOW_THRESHOLD, else THRESHOLDS_1M
  - Find the highest threshold that utilization has crossed
  - Check if that threshold has already been hit (via tracking.thresholds_hit)
  - If already hit: return false
  - Apply debounce: if tracking.last_checkpoint_epoch exists and (now - last_checkpoint_epoch) < debounceSeconds: return false
  - Return true (new threshold crossed, not debounced)
- Non-throwing (return false on error)

`async writeCheckpoint(params: WriteCheckpointParams): Promise<WriteCheckpointResult | null>` — Main write flow:
- Generate checkpoint_id via `ulid()`
- Get date prefix: `new Date().toISOString().slice(0, 10)` (YYYY-MM-DD)
- File basename: `${datePrefix}_${checkpointId}.yaml`
- Step 1: INSERT into checkpoint_meta: `(checkpoint_id, session_id, trigger, status='pending')`
- Step 2: Read current state from DB inside a read transaction:
  - `getDecisionsBySession(db, sessionId)` -> take first 15, map to CheckpointDecision[]
  - `getThreadState(db, sessionId)` -> map to CheckpointThread
  - `getHotFiles(db, project, 20)` -> map to CheckpointFiles.hot
  - `getTopLearnings(db, project, 10)` -> map to learnings string[]
  - Extract open items from lastAssistantText via extractOpenItems
  - Query for previous checkpoint: `SELECT checkpoint_id FROM checkpoint_meta WHERE session_id = ? AND status IN ('committed','mirrored') ORDER BY created_at_epoch DESC LIMIT 1`
    - Use basename only (security)
- Step 3: Build CheckpointV3 object with all gathered data
- Step 4: UPDATE checkpoint_meta: `status='committed', data=JSON.stringify(checkpoint)`
- Step 5: If enrichmentProvider provided:
  - Build CheckpointData from the checkpoint for enrichCheckpoint
  - Call `enrichCheckpoint(data, enrichmentProvider)`
  - If enrichment succeeds: `mergeEnrichment(data, enriched)` -> update checkpoint object with merged data
  - UPDATE checkpoint_meta: `data=JSON.stringify(enrichedCheckpoint)`
  - Set enriched=true
- Step 6: Serialize checkpoint to YAML via `js-yaml.dump()`
- Step 7: Write YAML file via `atomicWriteFile(filePath, yamlContent)`
  - filePath = `getCheckpointsDir(projectDir) + '/' + basename`
- Step 8: Update latest.yaml: `atomicWriteFile(getCheckpointsDir(projectDir) + '/latest.yaml', 'ref: ' + basename + '\n')`
- Step 9: UPDATE checkpoint_meta: `status='mirrored', mirror_path=filePath`
- Step 10: Record threshold hit via `recordThresholdHit` if trigger was threshold
- Return WriteCheckpointResult
- If any step after pending INSERT fails: UPDATE checkpoint_meta set error=errorMessage
- Non-throwing: wrap entire function in try/catch, return null on error

For the read section in step 2, also query observations that touched files:
- `SELECT DISTINCT json_each.value FROM observations, json_each(observations.files_modified) WHERE session_id = ? AND deleted_at_epoch IS NULL LIMIT 50` -> populate CheckpointFiles.read
