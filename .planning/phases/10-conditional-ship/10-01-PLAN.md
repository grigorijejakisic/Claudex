**routeFromArtifact (single artifact reference):**

```ts
export async function routeFromArtifact(
  db: Database,
  artifact: RoutingArtifact,
  opts: RoutingOptions = {},
): Promise<RoutingResult>
```

Implementation outline (follow hybrid-retrieval's defensive shape — non-throwing, graceful degradation at each external dependency):

1. Load `loadConfig().v6.routing` once; resolve the effective `top_k`, `reranker_mode` from opts + config.
2. Default time window: `window_ms_before = 2 * 60 * 60 * 1000` (2h), `window_ms_after = 2 * 60 * 60 * 1000` (2h). Spec note: this captures the deliberation context that produced the artifact; CONTEXT specifics ("session_id + time window from artifact's creation timestamp"). Operator can tune via opts.
3. Candidate fetch via SQL — straight SELECT against `transcript_chunk_v6`, no FTS / RRF / multipliers. Routing is a focused fan-out, not a hybrid:
   ```sql
   SELECT id, session_id, turn_index, sub_index, role, body, created_at_epoch_ms
   FROM transcript_chunk_v6
   WHERE session_id = ?
     AND created_at_epoch_ms BETWEEN ? AND ?
   ORDER BY turn_index ASC, sub_index ASC
   LIMIT 20
   ```
   Use `cachedPrepare` from `src/core/stmt-cache.ts` (mirrors hybrid-retrieval).
4. If candidates.length === 0, return `{ spans: [], bi_encoder_only: true, candidate_count: 0 }` immediately.
5. Build `query_text` for ranking: `artifact.query_text` if present, else fall back to a short summary derived from the first candidate's session — keep it 200-500 chars to mirror hybrid-retrieval's reranker payload limits.
6. Branch on `reranker_mode`:
   - `bi_encoder_primary` → call `rankWithBiEncoder` (Ollama /api/embed against snowflake-arctic-embed2). On Ollama unreachable, return candidates as-returned with `rank_score = 0` and `bi_encoder_only = true` — degraded but non-throwing.
   - `cross_encoder_primary` → call `rankWithCrossEncoder` (port 7439 /rerank, 3s timeout, mirror hybrid-retrieval's `ceFailureReason` capture). On non-2xx / timeout / unreachable / empty: increment `incrementRerankerFallbackCounter(db, opts.caller_session_id ?? 'unknown-session', reason)` then call `rankWithBiEncoder`.
7. Sort by `rank_score` descending, slice to `top_k`, return.

**routeFromArtifacts (multi-artifact fan-out with budget):**

```ts
export async function routeFromArtifacts(
  db: Database,
  artifacts: RoutingArtifact[],
  opts: RoutingOptions = {},
): Promise<RoutingResult>
```

1. Loop calls `routeFromArtifact` per artifact (sequential — these are I/O-bound network calls, parallel would saturate Ollama; mirror existing hybrid-retrieval discipline).
2. Concatenate all `spans` arrays.
3. Deduplicate by `chunk_id` (preserve highest `rank_score`).
4. Sort by `rank_score` descending.
5. Slice to `loadConfig().v6.routing.max_k_per_query` (default 12).
6. `bi_encoder_only = true` if ANY contributing call returned `bi_encoder_only=true` — Plan 10-02 uses this to apply the smaller budget conservatively.
7. Return.

**Internal helpers (private, not exported):**

- `rankWithBiEncoder(query, candidates) → Promise<RoutingSpan[]>`: Ollama /api/embed for query + each candidate body (max 500 chars per text), cosine similarity, attach `rank_score = cosine`, `ranker = 'bi_encoder'`. On any throw / non-200, return `candidates.map(c => ({ ...c, rank_score: 0, ranker: 'bi_encoder' }))`. Three-second timeout via `AbortSignal.timeout(3000)`.
- `rankWithCrossEncoder(query, candidates, db, callerSessionId) → Promise<{ spans: RoutingSpan[]; bi_encoder_only: boolean }>`: 7439 /rerank call with 3s timeout. On success: map indices back to candidates, normalize scores to 0..1, return `bi_encoder_only: false`. On any failure: capture reason (`non_2xx`/`timeout`/`unreachable`/`empty_response` per existing hybrid-retrieval taxonomy), call `incrementRerankerFallbackCounter`, fall through to `rankWithBiEncoder`, return `bi_encoder_only: true`.
