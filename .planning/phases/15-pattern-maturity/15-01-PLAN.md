# Plan 15-01: Pattern Maturity + Harmful Multiplier

## Goal
Experience patterns progress through maturity stages. Negative outcomes weighted 4× heavier. Anti-pattern inversion for persistently harmful patterns.

## Tasks

### Task 1: Schema changes
**Files:** `src/core/schema.ts`, `src/core/migrations.ts`

1. Add to experience_patterns DDL in schema.ts:
   - `maturity TEXT DEFAULT 'candidate' CHECK (maturity IN ('candidate', 'established', 'proven'))`
   - `confidence REAL DEFAULT 0.5`
2. In migrations.ts V11 step (same migration as Phase 13):
   - ALTER TABLE to add both columns
   - Backfill: patterns with `times_triggered >= 5 AND helpful_count >= 3` → 'proven'; `times_triggered >= 2` → 'established'; rest → 'candidate'
   - Backfill confidence: `(helpful_count + 1) / (helpful_count + harmful_count + 2)` (Laplace smoothing)

### Task 2: Maturity lifecycle in experience-patterns.ts
**File:** `src/intelligence/experience-patterns.ts`

Add functions:

1. `computeConfidence(pattern): number` — `(helpful + 1) / (helpful + harmful + 2)`
2. `checkMaturityPromotion(pattern): string | null` — returns new maturity or null:
   - candidate → established: `times_triggered >= 2 AND source sessions >= 2`
   - established → proven: `helpful_count >= 3 AND verification_count >= 2`
3. `applyHarmfulMultiplier(pattern, increment): void` — `score -= 4 * increment` (vs +1 for helpful)
4. `checkAntiPatternInversion(pattern): boolean` — if `harmful_count > helpful_count + 3`, transform lesson to explicit warning (prepend "WARNING: " to lesson, set pattern_type to 'behavioral')

Modify `findMatchingPatternsHybrid()` to:
- Filter by maturity: `candidate` patterns get 0.5× weight, `established` get 1.0×, `proven` get 1.5×
- Multiply retrieval score by `confidence`

### Task 3: Promotion + harmful scoring in stop hook
**File:** `src/adapters/cc-hooks/stop.ts`

In the existing pattern verification section:
1. After incrementing helpful/harmful counts, call `computeConfidence()` and update the column
2. Call `checkMaturityPromotion()` — if promotion returned, UPDATE maturity
3. If harmful incremented, call `applyHarmfulMultiplier()` with the increment
4. Call `checkAntiPatternInversion()` — if true, update the pattern's lesson and type
5. Add confidence decay: for all patterns NOT triggered this session, `confidence *= 0.995` (very slow decay — noticeable over 100+ sessions)

### Task 4: Tests
**File:** `src/tests/intelligence/experience-patterns.test.ts` (modify existing)

Add tests:
1. New pattern starts as candidate with confidence 0.5
2. Pattern triggered in 2nd session → promoted to established
3. Pattern with 3 helpful + 2 verified → promoted to proven
4. Pattern marked harmful: score drops 4× per harmful increment
5. Pattern with harmful > helpful + 3 → lesson inverted to warning
6. Confidence = (helpful+1)/(helpful+harmful+2) computed correctly
7. Candidate patterns get 0.5× weight in retrieval
8. Proven patterns get 1.5× weight in retrieval
9. Confidence decays slowly without reinforcement

### Task 5: Verify build + tests
