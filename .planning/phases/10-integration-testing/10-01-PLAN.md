**src/tests/integration/e2e-flows.test.ts** — Integration tests covering Architecture Section 14 scenarios 1, 2, 3 plus PERF-01 through PERF-04.

**Setup pattern**: Each describe block uses `beforeEach` that creates a fresh in-memory DB via `openDatabase(':memory:')`, runs `initializeSchema(db)`, and prepares common test values (sessionId, project, config with `provider: 'none'`). `afterEach` closes the DB.

- `makePiContext(messages, options?)`: Returns mock PiContext with `getContextUsage()` returning `{ inputTokens: 1000, outputTokens: 500, contextWindowTokens: 200000 }`

**describe('CC Hook E2E Flow')** — Scenario 1 from Architecture Section 14.

The test simulates the full CC hook lifecycle by calling the same core functions each hook calls, in sequence, against a single in-memory DB. This validates accumulated state transitions.

**Test: `full CC hook lifecycle produces correct accumulated state`**

Step 1 — SessionStart:
```
createSession(db, { session_id: 'test-session', project: 'test-project', scope: null, cwd: '/test', source: 'cc-hooks' })
recoverFromDb(db)
const payload = assembleFullContext({ db, project: 'test-project', projectDir: '/test', config, identityDir: undefined })
```
Verify: `getSession(db, 'test-session')` returns row with status 'active'. Assembly returns an InjectPayload (may have empty content on fresh DB — that's fine).

Step 2 — PostToolUse (x2, simulating two tool uses):
```
// Tool use 1: Edit a file
processToolObservation({ db, sessionId: 'test-session', project: 'test-project', toolName: 'Edit', toolInput: { file_path: '/test/src/main.ts', old_string: 'foo', new_string: 'bar' }, toolOutput: undefined, projectRoot: '/test' })
updatePressureScore(db, '/test/src/main.ts', 'test-project', 0.1)
const tracker1 = new ThreadTracker(db, 'test-session')
tracker1.onAfterTool(undefined, 'Edit', { file_path: '/test/src/main.ts' })
tracker1.persist()

// Tool use 2: Read a file
processToolObservation({ db, sessionId: 'test-session', project: 'test-project', toolName: 'Read', toolInput: { file_path: '/test/README.md' }, toolOutput: { content: 'Project readme contents' }, projectRoot: '/test' })
updatePressureScore(db, '/test/README.md', 'test-project', 0.1)
const tracker2 = new ThreadTracker(db, 'test-session')
tracker2.onAfterTool(undefined, 'Read', { file_path: '/test/README.md' })
tracker2.persist()
```
Verify: observations in DB — `getObservationsByProject(db, 'test-project')` returns at least the Edit observation (Read may be filtered by quality gate — either count is fine). Pressure scores: `getHotFiles(db, 'test-project', 10)` returns entries for touched files. Thread state: `getThreadState(db, 'test-session')` returns non-null.

Step 3 — Stop (turn end):
```
await captureDecisions({ db, sessionId: 'test-session', project: 'test-project', userText: 'Please rename foo to bar in main.ts', assistantText: 'I\'ll rename foo to bar as requested. Let me edit the file.', mode: 'after_turn' })
const tracker3 = new ThreadTracker(db, 'test-session')
tracker3.onAfterTurn('Please rename foo to bar in main.ts', 'I\'ll rename foo to bar as requested.')
```
Verify: Thread state updated (summary or key_exchanges populated).

Step 4 — PreCompact:
```
await writeCheckpoint({ db, sessionId: 'test-session', project: 'test-project', projectDir: '/test', trigger: 'compaction', scope: null })
promoteLearnings({ db, project: 'test-project', sessionLearnings: [] })
markPostCompactPending(db, 'test-session')
```
Verify: `getCheckpointTracking(db, 'test-session')` returns row with `post_compact_pending === 1`. Checkpoint meta exists in DB.

Step 5 — UserPromptSubmit (post-compaction):
```
const tracking = getCheckpointTracking(db, 'test-session')
const isPostCompaction = tracking?.post_compact_pending === 1
const regularPayload = assembleRegularPrompt({ isPostCompaction, prompt: 'What did we just do?', gauge: null, topicShift: null, db, project: 'test-project', projectDir: '/test', config, identityDir: undefined })
clearPostCompactPending(db, 'test-session')
```
Verify: `isPostCompaction` is true. After clear, `getCheckpointTracking(db, 'test-session')?.post_compact_pending` is 0.

Step 6 — SessionEnd:
```
await writeCheckpoint({ db, sessionId: 'test-session', project: 'test-project', projectDir: '/test', trigger: 'session_end', scope: null })
pruneObservations(db, 'test-project', { pruneThreshold: config.observations.prune_threshold, pruneCount: config.observations.prune_count })
applyRetentionPolicy(db, 'test-project', config.observations.retention_days)
decayPressureStratified(db)
endSession(db, 'test-session', 'completed')
pruneTelemetry(db, { retentionDays: config.observability.retention_days, retainErrorCount: config.observability.retain_error_count })
```
Verify: `getSession(db, 'test-session')` has status 'completed'. DB is in consistent state (no orphaned rows).
