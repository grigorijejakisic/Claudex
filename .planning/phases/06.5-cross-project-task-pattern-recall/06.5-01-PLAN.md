    **Classifier logic (regex-first, planner discretion per CONTEXT.md):**

    Pull canonical vocabulary from `shape_vocabulary` table (Phase 4.1 substrate):
    ```sql
    SELECT field, value FROM shape_vocabulary WHERE field = 'task_shape'
    ```

    Algorithm:
    1. **Direct shape match (highest confidence):** If `shape?.task_shape` is set AND it's in the canonical vocabulary → `{ task_pattern: shape.task_shape, confidence: 1.0 }`.
    2. **Regex over framing tokens (medium-high confidence):** For each canonical task_shape value, build a normalized token set (split on `-`, lowercase). Compute Jaccard overlap with `handles.user_framing_tokens`. If best match's Jaccard ≥ 0.5 → `{ task_pattern: bestMatch, confidence: 0.85 + (jaccard - 0.5) * 0.3 }` (caps at 1.0).
    3. **Files-touched topology (medium confidence):** Hardcoded patterns map (planner discretion — start with these, extend later):
       - `src/scraper.*` OR `errors_encountered` contains any of `['429', '403', 'rate-limit', 'cloudflare']` → `'scraping-rate-limit-investigation'` confidence 0.85
       - `prisma/migrations/*` OR `migrations/*` OR framing tokens contain any of `['ALTER', 'migration']` → `'schema-migration-design'` confidence 0.85
       - Files contain `auth/*`, `session*`, `token*` → `'auth-flow-design'` confidence 0.85
    4. **Abstain (confidence < 0.85):** Return `{ task_pattern: null, confidence: 0, source: <input> }`. Caller must NOT write a row.

    **Backfill logic:**

    ```sql
    SELECT a.id, a.artifact_type, a.summary, a.content
    FROM artifacts a
    LEFT JOIN artifact_task_pattern atp ON atp.artifact_id = a.id
    WHERE atp.artifact_id IS NULL
      AND a.artifact_type IN ('learning', 'observation', 'memory_file', 'flow', 'milestone')
    LIMIT ?
    ```

    For each row: synthesize a fake `TelemetryHandles` from `summary` + `content` (split on whitespace, lowercase, dedupe) — backfill is regex-only (no LLM, no shape lookup since legacy artifacts have no shape). Apply Step 1.3 (files topology) only on backfill. Write a row only if confidence ≥ 0.85; otherwise insert a sentinel row with `task_pattern='__abstain__'`, `confidence=0` so we never re-process the same row.

    Return aggregate counts: `{ classified, abstained, alreadyDone }`.
