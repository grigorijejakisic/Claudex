## Pre-flight lexical-leakage discipline

Every probe enforces an `expect(prompt).not.toMatch(/.../)` regex assertion BEFORE running detectTaskShape or assembleExperienceTier. If a prompt contains any of the forbidden lexical-surface tokens from its lesson, the assertion fails — guaranteeing that any pass is genuinely perceptual (handle + shape match) rather than FTS5 surface overlap. This is the kid-stove principle made testable.
