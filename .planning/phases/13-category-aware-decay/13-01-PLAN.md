# Plan 13-01: Category-Aware Decay + Stability Classification

## Goal
Different observation types decay at different rates. Implement stability classification and modify the decay engine accordingly.

## Tasks

### Task 1: Schema changes
**Files:** `src/core/schema.ts`, `src/core/migrations.ts`

1. Add `stability_class` column to observations DDL in schema.ts:
   ```sql
   stability_class TEXT DEFAULT 'standard' CHECK (stability_class IN ('transient', 'standard', 'stable', 'permanent'))
   ```
2. Add `novelty_score` column: `novelty_score REAL DEFAULT 0.5`
3. Add `consolidated_into` column: `consolidated_into INTEGER` (for Part 3 consolidation, add now to avoid second migration)
4. In migrations.ts, add V11 migration step:
   - ALTER TABLE to add the three columns
   - Backfill `stability_class` based on existing `category`:
     - `category IN ('error', 'test')` → 'transient'
     - `category IN ('architecture', 'decision')` → 'stable'
     - everything else → 'standard'

### Task 2: Auto-classify on insert
**File:** `src/core/observations.ts`

Add a `classifyStability(category: string): string` function:
```typescript
function classifyStability(category: string): string {
  if (['error', 'test'].includes(category)) return 'transient';
  if (['architecture', 'decision'].includes(category)) return 'stable';
  return 'standard';
}
```

Modify `insertObservation()` to set `stability_class` using this function when not explicitly provided.

### Task 3: Modify decay engine
**File:** `src/decay/decay-engine.ts`

Replace flat half-life lookup with stability-aware half-lives:

```typescript
const HALF_LIVES: Record<string, Record<number, number>> = {
  transient:  { 1: 3, 2: 7, 3: 14, 4: 30, 5: 90 },     // days
  standard:   { 1: 7, 2: 14, 3: 30, 4: 60, 5: 365 },
  stable:     { 1: 14, 2: 30, 3: 90, 4: 180, 5: Infinity },
  permanent:  { 1: Infinity, 2: Infinity, 3: Infinity, 4: Infinity, 5: Infinity },
};
```

Modify the EI computation to read `stability_class` from the observation row and use the appropriate half-life table. `Infinity` means never auto-decay (skip the decay computation).

### Task 4: Tests
**File:** `src/tests/decay/decay-engine.test.ts` (modify existing)

Add tests:
1. Error observation (transient) decays faster than architecture (stable) at same importance
2. Importance-5 stable observation never decays (Infinity half-life)
3. Backfill migration correctly classifies existing observations
4. `classifyStability()` returns correct class for each category

### Task 5: Verify build + existing tests
Run `bun run build` and `bun run test`. Zero regressions.
