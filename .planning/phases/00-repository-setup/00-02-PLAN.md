**src/shared/fs-helpers.ts** — File system utilities:

Exports:
- `atomicWriteFile(filePath: string, content: string): Promise<boolean>` — Writes to tmp file (filePath + '.tmp.' + random), then renames. On Windows (process.platform === 'win32'), if rename fails with EPERM, falls back to copy+chmod+unlink. Returns true on success, false on failure. Never throws. Creates parent directories with recursive mkdir if needed.
- `readJsonFile<T>(filePath: string): T | null` — Reads and JSON.parses a file. Returns null on any error (missing file, invalid JSON). Never throws.

- `ensureDir(dirPath: string): boolean` — Synchronous mkdirSync recursive. Returns true if dir exists after call, false on error. Never throws.

Cross-platform: atomicWriteFile has the ONE process.platform === 'win32' check for EPERM fallback (Architecture Section 15.5). This is one of the 2-3 allowed platform checks.

**src/shared/scope-detector.ts** — Project scope detection:

The scope detector maps a working directory to a project identifier by reading `~/.claudex/projects.json`. This file stores known project paths → project IDs.

Exports:
- `detectProjectScope(cwd: string): string | null` — Reads projects.json via readJsonFile, finds the longest matching project path prefix for the given cwd. Returns the project ID string or null if no match. Case-insensitive path comparison on Windows (process.platform === 'win32'). This is the SECOND allowed platform check. Never throws.
- `registerProject(cwd: string, projectId: string): Promise<boolean>` — Adds/updates a project entry in projects.json. Uses readJsonFile + writeJsonFile. Returns true on success. Never throws.
- `getProjectId(cwd: string): string` — Convenience: calls detectProjectScope, and if null, derives a project ID from the directory name (last segment of cwd, lowercased, sanitized to alphanumeric+hyphens). Never throws; always returns a string.

projects.json format:
```json
{
  "projects": {
    "/path/to/project": "my-project-id",
    "C:\\Users\\...\\MyProject": "my-project"
  }
}
```

Uses getProjectsJsonPath() from paths.ts to locate the file. Uses readJsonFile/writeJsonFile from fs-helpers.ts.
