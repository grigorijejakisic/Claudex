`estimateTokens(text: string): number`:
- If `!text` (null, undefined, empty string): return 0
- Return `Math.ceil(text.length / 4)`
- Non-throwing (return 0 on error)

Note: `src/shared/text-utils.ts` already has an `estimateTokens()` function with the same logic. The assembly module can either re-export it or import it. Decision: import and re-export from `text-utils.ts` to avoid duplication — add a re-export: `export { estimateTokens } from '../shared/text-utils.js';`

This keeps the assembly module self-contained (consumers import from `assembly/token-estimator`) while avoiding code duplication.

4. `returns 1 for single character` — `estimateTokens('a')` === 1

**src/assembly/sections.ts** — 10 stateless section formatters. All are pure functions taking pre-fetched data, returning `string | null`. All non-throwing (return null on error).

Import from existing modules:
- `renderCheckpointMarkdown` from `../checkpoint/inject.js`
- `CheckpointV3` from `../checkpoint/types.js`
- `LearningRow` from `../core/learnings.js`
- `PressureRow` from `../core/pressure.js`
- `ObservationRow` from `../core/observations.js`
- `GsdState` from `../gsd/types.js`
- `TokenUsage` from `../shared/types.js`
- `TopicShiftResult` from `../intelligence/topic-shift.js`
- `getIdentityDir`, `getHandoffsDir` from `../shared/paths.js`
- `fs` for file reads (identity, project)
- `path` for path joins

---

**1. `formatIdentitySection(identityDir?: string): string | null`**
- Read `USER.md` from `identityDir ?? getIdentityDir()`
- If file doesn't exist or is empty: return null
- Return: `## Identity\n{content}` where content is the file contents
- Non-throwing (return null on error)

**2. `formatProjectSection(projectDir: string): string | null`**
- Read `PROJECT_PRIMER.md` from `projectDir` root
- Read `ACTIVE.md` from `getHandoffsDir(projectDir)`
- If both missing/empty: return null
- Build sections:
  - If primer exists: `## Project\n{primerContent}`
  - If active handoff exists: append `\n\n## Active Handoff\n{activeContent}`
- Return combined string (one or both parts)
- Non-throwing

**3. `formatCheckpointSection(checkpoint: CheckpointV3 | null): string | null`**
- If no checkpoint: return null
- Delegate to `renderCheckpointMarkdown(checkpoint, 'RESUME')`
- If result is empty string: return null
- Return `## Checkpoint\n{renderedContent}`
- Non-throwing

**4. `formatLearningsSection(learnings: LearningRow[]): string | null`**
- If empty array: return null
- Format each learning as: `- {content} (x{promotion_count})`
- Return: `## Learnings\n{bulletList}`
- Non-throwing

**5. `formatHotFilesSection(hotFiles: PressureRow[]): string | null`**
- If empty array: return null
- Filter to files where `raw_pressure >= 0.851`
- If none remain after filter: return null
- Format each as: `- {file_path}` (include `(pressure: {raw_pressure.toFixed(2)})` for context)
- Return: `## Hot Files\n{bulletList}`
- Non-throwing

**6. `formatGsdSection(gsd: GsdState | null): string | null`**
- If no GSD: return null
- Build markdown:
  ```
  ## GSD State
  **Phase {phase}:** {goal}
  **Status:** {status}
  **Completion:** {completion}
  ```
- If success_criteria non-empty, append:
  ```
  **Success Criteria:**
  - {criterion1}
  - {criterion2}
  ```
- Return formatted string
- Non-throwing

**7. `formatFts5Section(observations: ObservationRow[], referenceMode?: boolean): string | null`**
- If empty array: return null
- If `referenceMode` is true (or unset defaults to false):
  - Compact format per observation: `- [{category}] {title} ({relativeTimestamp})`
  - Where `relativeTimestamp` = human-readable age (e.g., "2h ago", "3d ago")
- If `referenceMode` is false:
  - Full format: `### {title}\n*{category} | {relativeTimestamp}*\n{content}`
  - Separate entries with blank line
- Return: `## Relevant Observations\n{formattedList}`
- Non-throwing

Helper: `formatRelativeTime(epochSeconds: number): string` — internal helper
- Compute age in seconds from now
- < 60s: "just now"
- < 3600s: "{n}m ago"
- < 86400s: "{n}h ago"
- else: "{n}d ago"

**8. `formatRecentSection(observations: ObservationRow[]): string | null`**
- If empty: return null
- Always compact format (these are supplementary): `- [{category}] {title} ({relativeTimestamp})`
- Return: `## Recent Observations\n{bulletList}`
- Non-throwing

**9. `formatGaugeSection(gauge: TokenUsage | null, threshold?: number): string | null`**
- If no gauge: return null
- If `gauge.utilization < (threshold ?? 0.70)`: return null
- Return: `# Token Gauge\nUtilization: {pct}% ({inputTokens.toLocaleString()} / {contextWindowTokens.toLocaleString()})`
  - Where pct = `Math.round(gauge.utilization * 100)`
- Non-throwing

**10. `formatTopicPivotSection(params: { shift: TopicShiftResult; learnings?: LearningRow[]; hotFiles?: PressureRow[]; decisions?: Array<{ content: string; source: string }> }): string | null`**
- If `!shift.shifted`: return null
- Build sections:
  1. `## Context Pivot\nSwitching context: {previousTopic} -> {newTopic}`
  2. If learnings provided and non-empty (top 3): `\n\n**Relevant Learnings:**\n- {learning1}\n- {learning2}\n- {learning3}`
  3. If hotFiles provided and non-empty: `\n\n**Related Files:**\n- {file1}\n- {file2}`
  4. If decisions provided and non-empty: `\n\n**Related Decisions:**\n- {decision1}\n- {decision2}`
- Return combined markdown
- Non-throwing
