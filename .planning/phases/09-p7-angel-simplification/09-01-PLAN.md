# Plan 09-01 — Delete autonomous-investigator.ts (sub-phase 9.2)

## Goal

Delete `src/angel/autonomous-investigator.ts` and its sole heartbeat callsite
(Phase 4e3b). Per CONTEXT.md `<decisions>.### Module dependencies (T6-verified)`,
this module's only inbound caller is the heartbeat tick dispatcher; there are
no inbound consumers from `assembler.ts`, hooks, or other modules.

## Why this plan ships sub-phase 9.2 BEFORE sub-phase 9.1

CONTEXT.md lists the modules in semantic order (9.1 = `cara-reasoning.ts`,
9.2 = `autonomous-investigator.ts`). Source-code grep reveals
`autonomous-investigator.ts:21` imports `reinforceOpinion`, `weakenOpinion`,
`contradictOpinion`, and `Opinion` from `cara-reasoning.ts`. Deleting
`cara-reasoning.ts` first would leave `autonomous-investigator.ts` referencing
non-existent symbols — `bun run build` would fail mid-sub-phase, breaking
the bisectability discipline.

The CONTEXT.md sub-phase numbering (9.1, 9.2, …) is preserved as the
**canonical module label** in the plan frontmatter (`sub_phase: 9.2`). The
plan filename numbering (`09-01-PLAN.md`) reflects **execution order**.
Wave 1 ships 9.2 first; Wave 2 ships 9.1.
