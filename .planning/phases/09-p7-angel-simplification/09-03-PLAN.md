# Plan 09-03 — Delete consolidator.ts::runDreamConsolidation (sub-phase 9.3)

## Goal

Delete the `runDreamConsolidation` function and its `DreamResult` type from
`src/angel/consolidator.ts`, plus its sole heartbeat callsite (Phase 4e4).
The rest of `consolidator.ts` (observation-batch consolidation,
`shouldConsolidate`, `markConsolidationRan`, etc.) stays — those are still
called by Phase 7 of the heartbeat (line ~690-708).

## Why this is a function-level delete, not a file delete

CONTEXT.md sub-phase 9.3 reads `consolidator.ts::runDreamConsolidation` —
explicitly the function, not the whole module. `consolidator.ts` exports
multiple surfaces; only `runDreamConsolidation` and the dream-specific
helpers (`detectDreamReactivation`, `DreamResult` interface) are dead.
Heartbeat Phase 7 (`consolidateObservationBatch` + `shouldConsolidate` +
`markConsolidationRan`) is live and stays.

This is the only sub-phase in Phase 9 that does function-level pruning
inside a multi-export module. CONTEXT.md `<decisions>.### Test deletion`
applies surgically: delete dream-specific tests in
`src/tests/angel/consolidator.test.ts`, keep tests for the surviving
exports.

| File | Change |
