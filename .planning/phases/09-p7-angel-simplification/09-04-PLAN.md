# Plan 09-04 — Delete pattern-extractor.ts::crystallizePatternToSkill (sub-phase 9.4)

## Goal

Delete the `crystallizePatternToSkill` function from
`src/angel/pattern-extractor.ts` and its sole heartbeat callsite (Phase 4g,
"Skill crystallization"). Other exports of `pattern-extractor.ts`
(`extractPatternsFromSession`, `classifySessionDomains`, `getSessionTurns`)
stay — those are live consumers of the running pattern-extraction pipeline
inside heartbeat Phase 2.

Also delete the `skill-writer.ts` module if-and-only-if its only consumer
is the deleted `crystallizePatternToSkill`. Plan verifies this in task
09-04-01 before scoping the second deletion.

## Why this is a function-level delete

CONTEXT.md sub-phase 9.4 reads
`pattern-extractor.ts::crystallizePatternToSkill` — function-level, like 9.3.
The pattern-extractor module's other exports are Phase 2 / Phase 4.1
infrastructure that survived the broader Angel cuts. Only the
"crystallize proven patterns into SKILL.md files" surface (Phase 4g of
heartbeat) is dead.
