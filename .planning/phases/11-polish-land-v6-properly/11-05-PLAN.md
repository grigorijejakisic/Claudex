This is a skill-system modification + a script. No source-code changes in `src/`. Skill files live in `~/.claude/skills/<skill-name>/SKILL.md` (project-CLAUDE.md path conventions); this plan modifies user-global skill assets, not project-internal code. That's an unusual scope for a project-internal phase plan — make it explicit in the SUMMARY that the skill changes are user-global by design (the gate is meant to apply to every phase across every project, not just claudex-v3).

**The gate workflow:**

```
[phase work happens]
  ↓
[execute-phase or auto-orchestrate runs verify-work / sc3 / Vesna / etc.]
  ↓
[NEW: spawns scripts/external-review-gate.cjs --phase {N} --project {project}]
  ↓
[gate spawns Gemini ensemble pass; spawns Codex if reachable; collects findings]
  ↓
[gate classifies findings → signoff / block / log]
  ↓
  ├── signoff → phase-complete declaration proceeds
  ├── block   → phase stays open; findings rendered in {phase}-EXTERNAL-REVIEW.md; operator review required
  └── log     → phase-complete declaration proceeds; findings logged in {phase}-EXTERNAL-REVIEW.md as recommendations
```

**Codex unavailability handling:** CONTEXT § Operational constraints locks the rule — Codex unavailable until 2026-05-14; gate must NOT block on Codex unreachable; Gemini-only is the degraded-but-passing path. The gate emits a `degraded: true` flag in its verdict when Codex was skipped, and the {phase}-EXTERNAL-REVIEW.md notes the degradation.

**Operator override:** A `--skip-external-review` flag on the skill (and on the script) is available for emergency override. Usage logged to `.planning/external-review-overrides.log` per project. Default: gate runs.

1. Accept CLI arguments: `--phase <N>` (required), `--project <name>` (required), `--phase-dir <path>` (optional, derives from project + phase if absent), `--skip-codex` (optional, force-skip Codex even if reachable; useful for testing), `--out <path>` (optional, defaults to `{phase-dir}/{phase}-EXTERNAL-REVIEW.md`).

3. Spawn Gemini ensemble pass (4-judge per CONTEXT § Locked Decisions #3, but using a generic external-reviewer prompt distinct from the harness judge prompt — this is *code review*, not *engagement adjudication*).
4. Spawn Codex review when reachable (subprocess against `codex` CLI; on non-zero exit OR timeout > 60s, mark Codex degraded and proceed with Gemini-only).
5. Parse findings from each reviewer into a normalized shape: `{ severity: 'critical' | 'high' | 'medium' | 'low', finding: string, file?: string, line?: number, recommendation?: string }`.
6. Classify the verdict:
   - Any `severity: critical` finding → verdict: BLOCK; `signoff: false`.
   - Any `severity: high` finding → verdict: LOG (recommend); `signoff: true`.
   - Otherwise → verdict: SIGNOFF; `signoff: true`.
7. Write `{phase}-EXTERNAL-REVIEW.md` with: gate-verdict header, per-reviewer findings (Gemini ensemble + Codex if present), normalized classification, degradation note if Codex was unreachable.
8. Emit machine-readable JSON to stdout for the calling skill to read: `{ "signoff": boolean, "verdict": "SIGNOFF" | "BLOCK" | "LOG", "review_path": "...", "degraded": boolean, "findings_summary": { critical: N, high: N, medium: N, low: N } }`.
9. Exit code: 0 on signoff (incl. LOG with `signoff: true`), 1 on BLOCK, 2 on script-internal error.

```js
#!/usr/bin/env node
// scripts/external-review-gate.cjs
// Mandatory-default external-review gate for engineering + empirical phase close-outs.
// Per CONTEXT § Locked Decisions #6 + CONTEXT § Implementation Decisions § W2 (Q1).

const { execSync, spawn } = require('child_process');
const { readFileSync, writeFileSync, existsSync, readdirSync, mkdirSync, appendFileSync } = require('fs');
const { join, dirname } = require('path');

// ---------- arg parse ----------
const args = process.argv.slice(2);
const argMap = {};
for (let i = 0; i < args.length; i++) {
  const a = args[i];
  if (a.startsWith('--')) {
    const key = a.slice(2);
    const next = args[i + 1];
    if (!next || next.startsWith('--')) argMap[key] = true;
    else { argMap[key] = next; i++; }
  }
}
const phase = argMap.phase;
const project = argMap.project;
const skipCodex = !!argMap['skip-codex'];
const skipReview = !!argMap['skip-external-review']; // emergency override
if (!phase || !project) {
  console.error('Usage: external-review-gate.cjs --phase N --project name [--phase-dir path] [--skip-codex] [--skip-external-review] [--out path]');
  process.exit(2);
}

if (skipReview) {
  // Emergency override — log usage and pass through
  const logPath = '.planning/external-review-overrides.log';
  mkdirSync(dirname(logPath), { recursive: true });
  appendFileSync(logPath, `${new Date().toISOString()}\tphase=${phase}\tproject=${project}\n`);
  console.log(JSON.stringify({ signoff: true, verdict: 'OVERRIDE', review_path: null, degraded: false, findings_summary: {} }));
  process.exit(0);
}

// ---------- locate phase dir ----------
function findPhaseDir(phase) {
  if (argMap['phase-dir']) return argMap['phase-dir'];
  const phasesRoot = '.planning/phases';
  if (!existsSync(phasesRoot)) {
    console.error(`[gate] No .planning/phases/ in ${process.cwd()}`);
    process.exit(2);
  }
  const padded = String(phase).padStart(2, '0');
  const dirs = readdirSync(phasesRoot).filter((d) => d.startsWith(`${padded}-`));
  if (dirs.length !== 1) {
    console.error(`[gate] Could not uniquely resolve phase ${phase} dir; found: ${dirs.join(', ')}`);
    process.exit(2);
  }
  return join(phasesRoot, dirs[0]);
}
const phaseDir = findPhaseDir(phase);
const outPath = argMap.out || join(phaseDir, `${String(phase).padStart(2, '0')}-EXTERNAL-REVIEW.md`);

// ---------- build review bundle ----------
function buildReviewBundle() {
  const plans = readdirSync(phaseDir).filter((f) => f.endsWith('-PLAN.md'));
  const summaries = readdirSync(phaseDir).filter((f) => f.endsWith('-SUMMARY.md'));
  const bundle = {
    project, phase, phaseDir,
    plans: plans.map((f) => ({ file: f, content: readFileSync(join(phaseDir, f), 'utf8') })),
    summaries: summaries.map((f) => ({ file: f, content: readFileSync(join(phaseDir, f), 'utf8') })),
    roadmap: existsSync('.planning/ROADMAP.md') ? readFileSync('.planning/ROADMAP.md', 'utf8') : '',
  };
  return bundle;
}
const bundle = buildReviewBundle();

// ---------- reviewer prompts ----------
const REVIEWER_PROMPT = `You are an external code-review reviewer for project ${project}, phase ${phase}.
Read the phase's plan documents and execution summaries. Identify any:
- Logic bugs or correctness issues in the implementation as described
- Methodology concerns (especially for empirical phases)
- Missing test coverage for behaviors the plan claims to verify
- Mismatches between locked decisions in CONTEXT and what the SUMMARY claims was implemented
- Any silent-failure pattern (the v5.0.1 lesson — tests must assert visible failures, not just "no throw")

For each finding, output a JSON object with: severity (critical|high|medium|low), finding (1-2 sentence description), file (optional), line (optional), recommendation (optional 1-sentence fix).

Return findings as a JSON array on a single line, prefixed with the literal token \`FINDINGS:\`. Example: \`FINDINGS:[{"severity":"high","finding":"..."}]\`.

If no findings, return: \`FINDINGS:[]\`.

Phase materials:

${JSON.stringify(bundle).slice(0, 30000)}
`;

// ---------- Gemini ensemble ----------
async function runGeminiEnsemble() {
  // Per CONTEXT § Locked Decisions #3: gemini-3-flash via Ollama paid cloud passthrough (NOT gemini-cli — 429'd)
  // For external-review-gate use the same model line; the ensemble of 4 here would be overkill for code review.
  // Use 1 reviewer (gemini-3-flash-preview:cloud) — the 4-judge ensemble is reserved for empirical adjudication.
  // Document this discretion choice in 11-05-SUMMARY.md.
  try {
    const result = execSync(
      `ollama run gemini-3-flash-preview:cloud`,
      { input: REVIEWER_PROMPT, encoding: 'utf8', timeout: 120_000 },
    );
    const findings = parseFindings(result);
    return { reviewer: 'gemini-3-flash', findings, raw: result };
  } catch (err) {
    return { reviewer: 'gemini-3-flash', findings: [], raw: '', error: err.message };
  }
}

function parseFindings(raw) {
  const m = raw.match(/FINDINGS:\s*(\[.*\])/);
  if (!m) return [];
  try { return JSON.parse(m[1]); } catch { return []; }
}

// ---------- Codex (optional, may be unreachable) ----------
async function runCodex() {
  if (skipCodex) return { reviewer: 'codex', findings: [], raw: '', skipped: true, reason: 'skip-codex flag' };
  // Codex CLI usage limit until 2026-05-14 — try once, accept failure gracefully.
  try {
    const result = execSync(
      `codex review`,
      { input: REVIEWER_PROMPT, encoding: 'utf8', timeout: 60_000 },
    );
    return { reviewer: 'codex', findings: parseFindings(result), raw: result };
  } catch (err) {
    return { reviewer: 'codex', findings: [], raw: '', skipped: true, reason: err.message };
  }
}

// ---------- run + classify ----------
(async () => {
  const [gem, cdx] = await Promise.all([runGeminiEnsemble(), runCodex()]);
  const allFindings = [...gem.findings, ...cdx.findings];
  const summary = { critical: 0, high: 0, medium: 0, low: 0 };
  for (const f of allFindings) summary[f.severity] = (summary[f.severity] || 0) + 1;

  let verdict, signoff;
  if (summary.critical > 0) { verdict = 'BLOCK'; signoff = false; }
  else if (summary.high > 0) { verdict = 'LOG'; signoff = true; }
  else { verdict = 'SIGNOFF'; signoff = true; }

  const degraded = !!cdx.skipped;

  // Render markdown
  let md = `# External Review — Phase ${phase} (${project})\n\n`;
  md += `**Date:** ${new Date().toISOString()}\n`;
  md += `**Verdict:** ${verdict}\n`;
  md += `**Signoff:** ${signoff ? 'yes' : 'no — phase blocked pending operator review'}\n`;
  md += `**Degraded:** ${degraded ? 'yes — Codex unreachable, Gemini-only path' : 'no'}\n\n`;
  md += `## Findings summary\n\n| Severity | Count |\n|---|---|\n| critical | ${summary.critical} |\n| high | ${summary.high} |\n| medium | ${summary.medium} |\n| low | ${summary.low} |\n\n`;
  md += `## Reviewer: gemini-3-flash\n\n`;
  if (gem.error) md += `_Error during review: ${gem.error}_\n\n`;
  else if (gem.findings.length === 0) md += `No findings.\n\n`;
  else {
    for (const f of gem.findings) {
      md += `- **${f.severity}** ${f.finding}${f.file ? ` (${f.file}${f.line ? `:${f.line}` : ''})` : ''}${f.recommendation ? ` — _${f.recommendation}_` : ''}\n`;
    }
    md += '\n';
  }
  md += `## Reviewer: codex\n\n`;
  if (cdx.skipped) md += `_Skipped — ${cdx.reason}_\n\n`;
  else if (cdx.findings.length === 0) md += `No findings.\n\n`;
  else {
    for (const f of cdx.findings) {
      md += `- **${f.severity}** ${f.finding}${f.file ? ` (${f.file}${f.line ? `:${f.line}` : ''})` : ''}${f.recommendation ? ` — _${f.recommendation}_` : ''}\n`;
    }
    md += '\n';
  }
  md += `## Classification rule\n\nAny critical → BLOCK. Any high without critical → LOG (signoff with recommendations). Otherwise → SIGNOFF.\n`;

  mkdirSync(dirname(outPath), { recursive: true });
  writeFileSync(outPath, md);

  // Stdout JSON for calling skill
  console.log(JSON.stringify({ signoff, verdict, review_path: outPath, degraded, findings_summary: summary }));
  process.exit(signoff ? 0 : 1);
})();
```
