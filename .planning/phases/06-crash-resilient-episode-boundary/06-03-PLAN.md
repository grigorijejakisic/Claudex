<objective>
Wire all five CC hook entry points (UserPromptSubmit, PreToolUse, PostToolUse, Stop, SessionEnd) to update `sessions.last_heartbeat_ts` on every fire, and have SessionEnd emit the `clean_endsession` close marker atomically with the cursor advance.

Purpose: The composition rule in Plan 04 reads `last_heartbeat_ts` and `last_jsonl_write_ts` to decide ALIVE/DORMANT/TERMINATED. Without this plan, every session looks dead because no hook is writing the column. SessionEnd must short-circuit the boundary detector by writing the close marker itself — otherwise a clean `/endsession` could double-fire as `idle_timeout` later.

Output: 5 modified hook files + 1 regression test asserting the column writes happen.
</objective>

  <action>
Read the existing `session-end.ts`. The hook already calls `writeEnvironmentalEvent` for the existing session_boundary marker (per Phase 1) — confirm before editing. The new requirement is to ADDITIONALLY emit the `episode_closed` env event row with `close_reason='clean_endsession'`, advance `episode_boundary_cursor.last_close_event_id` for this session, and update `sessions.last_heartbeat_ts` — ALL in a single `db.transaction(() => { ... })()`.

Implementation pattern (mirrors Plan 04's transactional cursor + env event commit):

```typescript
// AFTER existing session_boundary write, BEFORE the hook returns:
try {
  const now = Math.floor(Date.now() / 1000);
  let closeEventId: number | null = null;

  const tx = db.transaction(() => {
    // 1) Bump heartbeat one last time so freshness checks downstream see clean close
    cachedPrepare(db,
      `UPDATE sessions SET last_heartbeat_ts = ?, status = 'completed', ended_at_epoch = COALESCE(ended_at_epoch, ?) WHERE session_id = ?`
    ).run(now, now, sessionId);

    // 2) Emit episode_closed env event row — close_reason='clean_endsession'
    //    short-circuits the composition rule.
    const ev = cachedPrepare(db,
      `INSERT INTO episodic_events
       (session_id, project, turn_number, type, source, content, provenance, parent_event_id, content_hash, metadata_json)
       VALUES (?, ?, NULL, 'environmental_event', 'angel-boundary', ?, 'environmental', NULL, ?,
               json_object(
                 'episode_closed', json('true'),
                 'close_reason',   'clean_endsession',
                 'last_heartbeat_ts', ?,
                 'duration_seconds', ?
               ))
       RETURNING id`
    ).get(
      sessionId,
      project,
      `Episode closed: clean_endsession`,
      sha256(`Episode closed: clean_endsession:${sessionId}`),
      now,
      // duration_seconds = now - sessions.created_at_epoch (best-effort)
      durationSeconds,
    ) as { id: number } | undefined;
    closeEventId = ev?.id ?? null;

    // 3) Advance cursor — UPSERT
    cachedPrepare(db,
      `INSERT INTO episode_boundary_cursor
         (project, session_id, last_processed_jsonl_offset, last_processed_event_ts_epoch, last_close_event_id)
       VALUES (?, ?, COALESCE((SELECT last_processed_jsonl_offset FROM episode_boundary_cursor WHERE project=? AND session_id=?), 0), ?, ?)
       ON CONFLICT(project, session_id) DO UPDATE SET
         last_processed_event_ts_epoch = excluded.last_processed_event_ts_epoch,
         last_close_event_id           = excluded.last_close_event_id`
    ).run(project, sessionId, project, sessionId, now, closeEventId);

    // 4) Telemetry — episode_close_emitted
    cachedPrepare(db,
      `INSERT INTO telemetry (session_id, event_kind, detail, adapter)
       VALUES (?, 'episode_close_emitted', json_object('close_reason','clean_endsession','close_event_id',?), 'angel-boundary')`
    ).run(sessionId, closeEventId);
  });
  tx();
} catch (err) {
  // Mirror episodic-events.ts captureError + recordEpisodicWriteFailure pattern.
  // Hook MUST NOT throw — log telemetry and continue.
  try {
    cachedPrepare(db,
      `INSERT INTO telemetry (session_id, event_kind, detail, adapter)
       VALUES (?, 'episodic_write_failure', json_object('hook','session-end','phase6','close-marker','error',?), 'session-end')`
    ).run(sessionId, (err as Error)?.message?.slice(0, 500) ?? String(err));
  } catch { /* last-resort: never let telemetry mask the failure */ }
}
```

Notes:
- Reuse `sha256` from `src/core/episodic-events.ts` if exported, or import `createHash` from `node:crypto` and inline the hash. Prefer reuse to avoid duplication.
- `durationSeconds` = compute as `now - row.created_at_epoch` from a `SELECT created_at_epoch FROM sessions WHERE session_id = ?` ABOVE the transaction (read-only; no need to be inside tx).
- Do NOT call `writeEnvironmentalEvent` here — its single-transaction model would conflict with our larger transaction. Inline the INSERT to keep all 4 statements (UPDATE, INSERT episodic, UPSERT cursor, INSERT telemetry) atomic.
- The `metadata_json` JSON shape must match exactly what Plan 04's boundary detector emits for non-clean_endsession close reasons, so consumers (Phase 7) read one consistent shape regardless of close path.
- `episode_closed` is NOT in the V25 CHECK constraint enum for `episodic_events.type`; we use `type='environmental_event'` per Phase 1's contract and put `episode_closed: true` in metadata_json. Confirm by reading the V25 CHECK constraint in schema.ts before submitting.
