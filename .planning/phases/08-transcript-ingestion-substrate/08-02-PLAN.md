```ts
import { parseWrappers } from '../extraction/wrapper-parser.js';

export interface JsonlTurn {
  session_id: string;
  project_id: string;
  turn_index: number;
  role: 'user' | 'assistant' | 'tool' | 'system';
  body: string;
  created_at_epoch_ms: number;
  provenance: 'organic' | 'injected' | 'tool_result' | 'environmental';
}

export interface ChunkV6 {
  session_id: string;
  project_id: string;
  turn_index: number;
  role: 'user' | 'assistant' | 'tool' | 'system';
  provenance: 'organic' | 'injected' | 'tool_result' | 'environmental';
  sub_index: number; // 0 for single-chunk turns; ≥1 for sentence-boundary sub-chunks
  body: string;
  created_at_epoch_ms: number;
  wrapper_redacted: boolean;
}

export const SOFT_TOKEN_LIMIT = 1500;
const TOKENS_PER_WORD = 0.75; // same proxy used in assembly token-budget code

export function chunkTranscript(turns: JsonlTurn[]): ChunkV6[] {
  // For each turn:
  //   1. Run parseWrappers(turn.body) → { organic, injected[] }
  //   2. wrapper_redacted = injected.length > 0
  //   3. body = organic
  //   4. If approxTokenCount(body) <= SOFT_TOKEN_LIMIT → emit one chunk with sub_index=0
  //      Else → split body at sentence boundaries (/(?<=[.!?])\s+/) and
  //              greedily pack into sub-chunks of <= SOFT_TOKEN_LIMIT, emit
  //              one chunk per split with the SAME (session_id, turn_index,
  //              role) but ascending sub_index (0, 1, 2, ...). The V32 schema's
  //              UNIQUE(session_id, turn_index, role, sub_index) absorbs
  //              re-ingestion idempotently — sub_index disambiguates.
}
```

Schema reconciliation is locked in plan 08-01: `transcript_chunk_v6` carries a `sub_index INTEGER NOT NULL DEFAULT 0` column with UNIQUE(session_id, turn_index, role, sub_index). The chunker emits sub_index=0 for the unsplit case and 0..N-1 for the split case.

Implementation specifics for the chunker:

- `parseWrappers` returns `{ organic, injected: WrapperBlock[] }`. The chunker uses `organic` as the chunk body. `wrapper_redacted = injected.length > 0`.
- Sentence-boundary split regex: `/(?<=[.!?])\s+/`. After splitting, greedily pack sentences into sub-chunks of ≤ SOFT_TOKEN_LIMIT.
- Token counter: `approxTokenCount(s: string): number` = `Math.ceil(s.split(/\s+/).filter(Boolean).length / TOKENS_PER_WORD)`. Same proxy used elsewhere in the codebase.
- If a single sentence exceeds SOFT_TOKEN_LIMIT, leave it intact (do NOT word-split — preserves sentence integrity for retrieval). This is rare in practice; do not over-engineer.
- Chunker is pure: no DB, no I/O, no clock reads. `created_at_epoch_ms` carries through from the turn.

Tests in `src/tests/ingestion/transcript-chunker-v6.test.ts`:

- Empty turns array → empty output.
- One short user turn → one chunk, `wrapper_redacted=false`, body matches input.
- One short turn containing a `<system-reminder>` block → one chunk, `wrapper_redacted=true`, body has the wrapper stripped.
- One 5000-token assistant turn → multiple chunks each ≤ SOFT_TOKEN_LIMIT, all with same `turn_index`/`role`/`session_id`/`project_id`, ascending `sub_index` (0, 1, 2, ...), sentence boundaries preserved (no mid-sentence cut).
- Single-chunk case → exactly one output with `sub_index=0`.
- Mixed-modality turn with `<command-message>` + `<file-content>` → wrapper_redacted=true, both wrapper types stripped.
- Provenance values pass through unchanged from the input turn.
- Idempotency property: `chunkTranscript(turns)` is deterministic for the same input.
