<objective>
Land the V32 schema bump that adds the v6 transcript-chunk substrate alongside the existing schema. Two new tables: a `transcript_chunk_v6` metadata table (chunk text, provenance, session/project/turn keys) and a paired `vec_transcript_chunks_v6` vec0 virtual table (1024-dim float embeddings, rowid-keyed to the metadata table).    - `id INTEGER PRIMARY KEY AUTOINCREMENT` — rowid keys vec_transcript_chunks_v6
   - `session_id TEXT NOT NULL`
   - `project_id TEXT NOT NULL`
   - `turn_index INTEGER NOT NULL`
   - `sub_index INTEGER NOT NULL DEFAULT 0` — 0 for single-chunk turns; ≥1 for sentence-boundary sub-chunks of long turns (CONTEXT decision 1 sub-chunk rule)
   - `role TEXT NOT NULL CHECK (role IN ('user','assistant','tool','system'))`
   - `provenance TEXT NOT NULL CHECK (provenance IN ('organic','injected','tool_result','environmental'))` — closed enum matching V25 episodic_events.provenance + V30/V31 learnings.provenance
   - `body TEXT NOT NULL`
   - `created_at_epoch_ms INTEGER NOT NULL`
   - `wrapper_redacted INTEGER NOT NULL DEFAULT 0` — 1 if parseWrappers stripped at least one wrapper block from the source turn
   - Two indexes: `(session_id, turn_index)` and `(project_id, created_at_epoch_ms)`
   - One UNIQUE index: `(session_id, turn_index, role, sub_index)` — re-ingestion of the same session+turn+sub-chunk is structurally idempotent; multiple sub-chunks of one long turn coexist via the `sub_index` column
