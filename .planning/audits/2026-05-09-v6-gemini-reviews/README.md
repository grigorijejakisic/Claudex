## Three independent reasons the +0.0038 bind doesn't hold

Each, by itself, sufficient to overturn the verdict:

1. **Harness B-arm uses dense vector KNN over the entire substrate; production routing uses temporal SQL hard-join.** The empirical result doesn't transfer to the shipped code path. (Review 04, Finding 2.)
2. **Three-prong rubric requires "cite specifically with `session_id` + `turn_index`"; A-arm context strips this metadata while B-arm is fed it explicitly.** The lift partly measures metadata access, not deliberation engagement. (Review 04, Finding 1.)
3. **Pooling treats r1 + r2 as n=60 independent samples, but they ran the same 30 probes with different seeds.** Repeated measurements of identical queries are not independent samples. The Wilson CI lower bound +0.0038 was generated by statistically illegitimate sample-size inflation. At a methodologically valid n=30, INCONCLUSIVE. (Review 04, Finding 4.)

## What's not changing

The v6 thesis — deliberation surfacing on the parable substrate — is **not invalidated** by these findings. The substrate (Phase 8) is solid. The routing layer (Phase 10) needs only the two B- one-line fixes. The assembly integration needs three regressions fixed. The methodology needs the rebind redone with corrected harness, paired statistics, and a multi-judge ensemble across families.

**Phase 11 lands v6.0.0 once, with whatever annotation the corrected verdict produces** — positive, kill receipt, or inconclusive. Each pre-committed outcome is locked in `.planning/research/2026-05-09-v6-polish.md`.
