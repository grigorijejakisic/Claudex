## Decisions
- Renamed approach from "Proactive Retrieval" to "Smart Retrieval + Intent Prediction" (honesty about what's reactive vs proactive)
- Strong anticipation (coupling) as default, weak anticipation (model) as fallback — not the reverse
- 70/30 rule: aim for 30%+ reference rate, not 100% prediction accuracy
- Forward-provisioned artifact_access_log and knowledge_gaps tables for future ACT-R BLL and System 3

## Learnings
- Research as adversarial process: 5-layer model (what exists, why it works, what's wrong, what's adjacent, what's next) produces fundamentally better architecture decisions than single-layer search
- Three-model review catches different bug classes: Gemini finds architectural gaps, Codex finds functional bugs, Claude finds live wiring issues
- Parallel execution workers need explicit file ownership boundaries to avoid conflicts
