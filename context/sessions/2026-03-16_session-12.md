## Learnings
- CC hook protocol requires hookSpecificOutput wrapper — top-level fields silently ignored
- Path matching needs boundary enforcement (/ or end-of-string) to prevent prefix collisions
- Unregistered project IDs must use same derivation everywhere or data fragments
- Global search without LIMIT can blow up context budget and drop entire materialization section
- Cross-project materialization contaminates source project's artifact state — scope mutations locally
- 12-agent multi-model review catches bugs single-model review misses (cross-model consensus)
