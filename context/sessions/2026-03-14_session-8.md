## Decisions Made

- Replace budget-cascade with reference + materialization (IAM-inspired)
- Flow entries include "why" as retrieval hints for FTS5 materialization
- TTL-based lifecycle replaces consumed flag (fresh→packed→materialized)
- Compaction = packing (lossless), not compression (lossy)
- Artifact threshold = 5 (legacy fallback when < 5 artifacts)
- Deprecate legacy sections, don't delete (safety net)
- Temporal awareness in every gauge injection

## Learnings

- IAM project's artifact system validates at 128K with weaker model — same pattern works for Claude at 1M
- Worktree isolation prevents file conflicts but also prevents shared context (caused schema mismatch between waves)
- Always commit unstaged changes before spawning workers (stash/merge dance was painful)
- Dead code analysis catches disconnected architecture — critical for parallel development
- The "make the right thing easy, make the wrong thing hard" principle from IAM design philosophy applies to Claudex
- Codex has usage limits — plan review timing or purchase credits
