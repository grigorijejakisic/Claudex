## Learnings

- **`tasklist | grep run-precision` is wrong on Windows.** Process names are all `node.exe`. Use `wmic process where "name='node.exe'" get processid,commandline | grep run-precision`. Burned ~15 min debugging a "dead" process that was alive.
- **`run-precision.cjs` writes startup line + final summary only.** All per-candidate work is silent. 79-byte log for 50+ min is expected, not a failure signal.
- **Don't pipe `run-precision.cjs` output to `head`/`tail`.** When the consumer exits, harness dies on SIGPIPE before writing final output. Redirect to a file instead.
- **Re-label "audit-vs-gold" disagreements shouldn't be rubber-stamped.** My own audit was wrong on 33% of the cases I'd marked "HUMAN more defensible." Having the user pass each case fresh caught real errors.
- **Orchestrator `tasklist` snapshots are unreliable.** Execute-3 was committing continuously while I thought it was idle-spinning; my git log checks weren't timed to catch them. Trust the teammate's committed work, not your snapshot diagnostics.
