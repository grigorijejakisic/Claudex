# Session: Evolved Flow — Recall Metadata + Retrieval Bridge
Date: 2026-03-21
Session: 22

## Flow
User showed a real conversation transcript where retrieval failed catastrophically — 3 sessions, ~80 tool calls to find a VBS startup script conversation because FTS5 couldn't match human recall cues to stored tokens. Analyzed 5 failure patterns (keyword literalism, source fixation, hypothesis lock-in, breadth resistance, evidence avoidance). Identified root cause: Flow entries were 300-char technical summaries with no FTS5 index — stored what the system saw, not what the human experienced. Designed Evolved Flow: recall metadata (aliases in user's voice, narrative, situational tags) stored at session boundaries + systematic search cascade protocol. Built, reviewed by Gemini (A-) and Codex (found 2 real criticals + recommendations), fixed all findings. Attempted auto-endsession daemon — overengineered, removed. User corrected rushing pattern: feedback during design iteration is NOT implicit approval to build.

## Decisions Made
- Recall aliases must be in user's voice, not LLM's technical paraphrase
- Three-tier degradation: /endsession (best) > Stop hook heuristic (good) > crash recovery (floor)
- Boundary-only recall writes (topic shift or compaction) to avoid per-turn write amplification
- Auto-endsession daemon: designed, built, deleted — overengineered for current needs, parked for Nexus
- User framings redacted before storage (security: prompts may contain secrets)
- detectIdleSession removed — compaction-based detection unreliable on 1M context windows

## Learnings
- Human memory is associative ("that openclaw script problem"), LLM search is lexical (FTS5 tokens). The bridge is storing how the user would search for this later.
- The 5 recall alias generation signals: repetition, first framing, structural markers, concept evolution, user's voice
- Flow's original vision was right but implementation was too thin (300-char technical summaries, no FTS5)
- Codex F grade was inflated — 3 of 5 criticals were pre-existing, not our code
- During design iteration: feedback is NOT implicit approval. Questions are NOT "proceed." HARD RULE.
