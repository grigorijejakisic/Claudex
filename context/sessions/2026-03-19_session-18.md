## Decisions Made
- Daemon code belongs to Nexus, not Claudex — clean product separation
- Claudex Recall uses artifact pipeline (not sqlite-vec) — Gemini correctly identified over-engineering
- Trigger engine uses app-level glob matching (not SQL GLOB) for performance
- Retrieval feedback has NO "Ignored" penalty — preventative patterns succeed silently
- Smoke tests in build.ts, not as a separate CI step — catches bugs before hooks register
- Behavioral gates use fs.stat mtime (not session events) — deterministic regardless of who triggered build
- Rules should be system-enforced, not text files the model may ignore
- Live testing is mandatory — unit tests are necessary but insufficient
