## Learnings
- loginctl enable-linger is REQUIRED for systemd user services to survive SSH disconnect
- SSH private key permissions on Windows: chmod doesn't work, use icacls
- Claude Code OAuth tokens are scoped to CC only — can't be used for OpenClaw API calls
- Always transfer OAuth tokens during migration (repeated Vesna mistake)
- OpenClaw plugin manifest needs kind:"memory" (not "context") to match memory slot
- US de minimis eliminated May-Aug 2025 — dropshipping structurally broken for US
