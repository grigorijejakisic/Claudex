## Learnings

- wrapHook's catch-all pattern makes ALL hook bugs invisible — stderr logging is essential
- Tests against fresh schemas cannot catch v2/v3 constraint mismatches — v2 fixture tests prevent this class of bug
- projects.json format mismatch went unnoticed because scope detection silently returned null (non-throwing pattern hid the bug)
- Module-level variables don't work as cross-process guards in CC hooks (each invocation is a separate Node process)
- 6,600+ observations were misrouted to __global__ because scope detection was broken since day one
